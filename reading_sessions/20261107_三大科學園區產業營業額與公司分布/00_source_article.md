## 2. 資料蒐集方法 (Data Collection Methodology)
* **目標母體與抽樣邊界**：
  * **母體定義**：國家科學及技術委員會轄下三大科學園區（新竹科學園區、中部科學園區、南部科學園區）內所有已入區營運並申報銷售額之園區廠商【官方已說明】。
  * **地理與園區邊界**：涵蓋三大科學園區共 15 個子園區——竹科（新竹、竹南、龍潭、新竹生醫、銅鑼、宜蘭）、中科（台中、虎尾、后里、二林、中興）、南科（臺南、高雄、橋頭、楠梓）【檔案觀察】。
  * **抽樣機制**：母體普查／全量廠商申報書彙整（非抽樣調查；平臺標示「資料集上架方式：原始資料」）【官方已說明】（依 `dataset/7597` 描述，係由園區廠商之申報書銷售額、收據合計等核算彙總）。
* **蒐集工具與管道**：
  * **原始管道**：依據園區廠商營業稅申報書銷售額、收據合計、銷貨退回及折讓、前期銷售額調整，扣除代收代付、出售固定資產、出售廢料、利息收入、樣品贈送等可抵減項目後，由各科學園區管理局與國科會彙整產製【官方已說明】（引自 https://data.gov.tw/dataset/7597 ）。
  * **人工介入與二次轉譯**：【未查得】（未知機關端於廠商申報資料異常或跨期調整時之人工稽核流程）。
* **時間範圍與取樣頻率**：
  * **記錄起迄時間**：`2025-01-01` 至 `2025-12-31`（2025 全年度累計值）【推論待確認】（依數值與國科會 2025 年營運記者會數據比對推論）。
  * **取樣與更新頻率**：**不定期更新**【官方已說明】（引自 https://data.gov.tw/dataset/7597 「更新頻率：不定期更新」）。
  * **資料性質**：單一統計期間之橫斷面彙整快照（Cross-sectional Aggregated Snapshot），不含時間序列維度欄位【檔案觀察】。
* **混合層級與彙整列觀察**：
  * 本檔共 `19` 筆資料列，明確存在**三種互斥的資料彙整層級**【檔案觀察】：
    1. **子園區明細列（共 `15` 筆）**：第 1～6 列（竹科 6 子園區）、第 8～12 列（中科 5 子園區）、第 14～17 列（南科 4 子園區）。
    2. **園區小計列（共 `3` 筆，`子園區 == '合計'`）**：第 7 列（`園區別='新竹科學園區', 子園區='合計'`）、第 13 列（`園區別='中部科學園區', 子園區='合計'`）、第 18 列（`園區別='南部科學園區', 子園區='合計'`）。
    3. **全區總計列（共 `1` 筆，`園區別 == '總計'` 且 `子園區 == '總計'`）**：第 19 列。
  * 類別欄位中包含已命名之「其他」彙總欄位：`其他產業營業額(億元)`，係作為六大核心產業以外之園區廠商營業額加總【檔案觀察】。

## 3. 資料清洗與前處理血統 (Data Lineage & Preprocessing Transformations)
* **【機關端前處理血統】**：
  * **上游原始資料來源**：國科會科學園區廠商營運／銷售額申報統計系統（下載端點為 `mas.nstc.gov.tw/OPENDATA/GetFile?format=csv&serialno=73&fileodr=0`）【官方已說明】。
  * **重複值處理（去重唯一鍵）**：匯出之統計表以 `('園區別', '子園區')` 雙欄位組合為唯一識別鍵，全檔 `19` 筆組合完全唯一無重複【檔案觀察】；至於機關端對上游廠商申報明細去重之規則為【未查得】。
  * **遺漏值（Missing Values）策略**：全檔 `19` 列 × `10` 欄共 `190` 個儲存格中，空字串或 `NULL` 數量均為 `0`。部分子園區於特定產業無營業額者（如楠梓園區全部產業、橋頭園區除積體電路外之產業、新竹生醫園區除生物技術外之產業），均以數值 `'0'` 填列【檔案觀察】。
  * **異常值與離群值判定**：【未查得】（機關端是否對個別廠商極端申報值進行人工查核未見說明）。
  * **特徵轉換、縮放與衍生變數**：
    * **銷售淨額核算公式**：`營業額 = 銷售淨額（含申報書銷售額 + 收據合計 - 銷貨退回及折讓 ± 前期銷售額調整） - 可抵減項目（代收代付 + 出售固定資產 + 出售廢料 + 利息收入 + 樣品贈送）`【官方已說明】（引自 https://data.gov.tw/dataset/7597 ）。
    * **單位縮放與四捨五入**：所有金額欄位均縮放以「新臺幣億元」為單位，並四捨五入保留至小數點後第 2 位（尾數為 `.00` 或 `.x0` 者在 CSV 中省略尾零，如 `'0'`, `'12881.3'`, `'29705.4'`）【檔案觀察】。
    * **衍生小計／總計與尾差現象**：經 Python 實測核對，機關端之「合計」與「總計」並非以本表四捨五入後之小數直接相加，而是以**上游未四捨五入之原始精確金額加總後再各自四捨五入**【檔案觀察】【推論待確認】。因此本檔內存在 $\pm 0.01$ 億元之正常四捨五入尾差（Rounding Discrepancy）：
      * **橫向加總尾差（7 項產業相加 vs `總計營業額(億元)`）**：`竹南園區`（橫向和 `564.71` vs 總計欄 `564.72`，差 `-0.01`）、`龍潭園區`（橫向和 `315.29` vs 總計欄 `315.28`，差 `+0.01`）、`宜蘭園區`（橫向和 `14.57` vs 總計欄 `14.56`，差 `+0.01`）、`虎尾園區`（橫向和 `57.44` vs 總計欄 `57.45`，差 `-0.01`）【檔案觀察】。
      * **縱向加總尾差（子園區相加 vs 園區`合計`列）**：竹科之積體電路（子園區和 `12881.29` vs 合計列 `12881.3`）、電腦及周邊（`1241.13` vs `1241.12`）、精密機械（`675.29` vs `675.28`）；中科之積體電路（`9419.61` vs `9419.6`）、光電（`1211.72` vs `1211.73`）、其他產業（`53.16` vs `53.17`）均差 $\pm 0.01$ 億元【檔案觀察】。
      * **全區總計尾差（3 園區`合計`相加 vs `總計`列）**：積體電路（`48292.64` vs `48292.63`）、通訊（`645.75` vs `645.76`）、精密機械（`1808.25` vs `1808.26`）、其他產業（`294.40` vs `294.39`）均差 $\pm 0.01$ 億元【檔案觀察】。
  * **去識別化與隱私防護**：本資料集已按「子園區 × 產業別」高度聚合（Aggregation），不含任何單一企業名稱、統一編號或個人可識別資訊（PII）【檔案觀察】。

## 6. 已知限制與外推邊界 (Known Limitations & Caveats)
* **抽樣偏差與涵蓋盲區 (Sampling Bias & Coverage Gaps)**：
  * **僅涵蓋國科會轄下三大科學園區入區廠商**：未進入科學園區設廠之高科技企業（例如位於經濟部產業園區／加工出口區、地方政府工業區或一般都市計畫區之 IC 設計、光電、生技、機械廠商），其營業額均不在本資料集涵蓋範圍內【檔案觀察】【官方已說明】。
  * **新設／開發中園區之零值現象**：例如南部科學園區之「楠梓園區」各產業營業額均為 `0`，橋頭園區僅積體電路產業有 `0.6` 億元【檔案觀察】。這反映特定子園區於該統計年度尚處於建廠或初期營運階段，不代表該地區無相關投資或產業活動。
* **前處理帶來的資訊損失 (Information Loss)**：
  * **廠商個體分布資訊完全損失**：資料已按「子園區 × 產業別」聚合為單一總和，無法得知各子園區內之廠商總家數、營收中位數、標準差或龍頭大廠集中度（如單一晶圓代工大廠佔比）【檔案觀察】。
  * **時間季節性資訊損失**：全年度聚合為單一靜態數值，且檔案內未附帶「年度／期別」欄位，無法單靠此檔觀察各雙月／季度或歷年之景氣波動【檔案觀察】。
  * **四捨五入尾差**：因數值縮放至「億元」並取小數點後兩位，橫向與縱向加總存在 $\pm 0.01$ 億元（約新臺幣 100 萬元）之四捨五入尾差【檔案觀察】。
* **外推邊界警告 (Extrapolation Boundaries)**：
  1. **【合計列重複計算風險 (Double Counting)】 → 絕對不能將全檔 `19` 列直接加總或取平均來推論全國科學園區規模**：因為第 7、13、18 列為三大園區之「合計」列，第 19 列為全區「總計」列。若分析時未先剔除這 4 列彙整列，任何總和（Sum）、平均值（Mean）或佔比（Share）分析都會發生嚴重的重複計算（總營業額會被算成 `174,030.69` 億元，恰為真實總計 `58,010.23` 億元的 3 倍）【檔案觀察】。
  2. **【生態謬誤 (Ecological Fallacy)】 → 不能從「子園區總營業額極高」推論「該園區內所有個別企業營收皆高或獲利能力皆強」**：例如臺南園區積體電路營業額高達 `25,759.91` 億元（佔全國科學園區總營收 `44.41%`）【檔案觀察】，但高度聚合數據可能由極少數超大型先進製程晶圓代工廠貢獻絕大多數營收，不能直接外推為該子園區內中小型廠商之平均營收表現，亦不能將「營業額（銷售淨額減可抵減項目）」直接等同於「附加價值（Value Added）」或「稅後淨利（Net Profit）」。
  3. **【母體涵蓋偏差】 → 不能將本表各產業佔比直接外推為「全臺灣整體科技產業結構」**：例如本表中積體電路產業佔科學園區總營業額高達 `83.25%`（`48,292.63 / 58,010.23`），電腦及周邊產業僅佔 `3.30%`（`1,917.20 / 58,010.23`）【檔案觀察】；這是因為晶圓製造高度集中於科學園區，而許多大型電腦品牌與伺服器系統組裝廠設址於科學園區外（如桃園、新北等地工業區）或採海外生產，故不可外推為全國總體產業產值比例。

## 7. 可執行 Python 防呆載入與分流程式（經實測驗證）

> **環境與依賴說明**：需安裝 `pandas`（Python 3.8+）。以下程式碼已針對實際檔案 `國家科學及技術委員會科學園區產業營業額統計表.csv` 實測執行驗證通過，確認無欄名撞名、無數值轉型失敗，且三層分流（15 筆明細 + 3 筆合計 + 1 筆總計 = 19 筆）完全互斥吻合。

```python
import csv
import pandas as pd

def load_nstc_science_park_revenue(csv_path: str):
    """
    載入並驗證《國家科學及技術委員會科學園區產業營業額統計表.csv》 (data.gov.tw/dataset/7597)
    保留原檔不改動，於記憶體副本執行欄名清理、安全數值轉型與三層彙整分流。
    """
    # 1. 嚴格位元組編碼檢測
    with open(csv_path, 'rb') as f:
        raw_bytes = f.read()
    has_bom = raw_bytes.startswith(b'\xef\xbb\xbf')
    
    decoded_text = None
    used_encoding = None
    for enc in ['utf-8-sig', 'utf-8', 'cp950', 'big5']:
        try:
            decoded_text = raw_bytes.decode(enc)
            used_encoding = enc
            break
        except UnicodeDecodeError:
            continue
            
    if decoded_text is None:
        raise ValueError(f"無法以候選編碼 (utf-8-sig, utf-8, cp950, big5) 解碼檔案：{csv_path}")
        
    # 2. 初始以純字串讀取，關閉預設 NA 解析以防吞掉特殊代碼
    df_raw = pd.read_csv(csv_path, encoding=used_encoding, dtype=str, keep_default_na=False)
    
    # 3. 清理欄名首尾空白與隱形字元，並防範撞名
    orig_cols = list(df_raw.columns)
    clean_cols = [c.replace('\ufeff', '').replace('\u200b', '').strip() for c in orig_cols]
    if len(set(clean_cols)) != len(clean_cols):
        raise ValueError(f"欄名清理後發生重複撞名：{clean_cols}")
    col_mapping = dict(zip(orig_cols, clean_cols))
    
    df = df_raw.copy()
    df.columns = clean_cols
    
    # 4. 針對已確認之數值欄位進行安全轉型（分開檢查原始空值與轉型失敗，絕不靜默轉 NaN）
    num_cols = [
        '積體電路產業營業額(億元)', '光電產業營業額(億元)', '電腦及周邊產業營業額(億元)',
        '通訊產業營業額(億元)', '精密機械產業營業額(億元)', '生物技術產業營業額(億元)',
        '其他產業營業額(億元)', '總計營業額(億元)'
    ]
    for col in num_cols:
        if col not in df.columns:
            raise KeyError(f"缺少預期數值欄位：{col}")
        s_clean = df[col].str.strip().str.replace(',', '', regex=False)
        empty_mask = (s_clean == '')
        if empty_mask.any():
            raise ValueError(f"欄位 [{col}] 發現 {empty_mask.sum()} 筆原始空值，中止轉型！")
        converted = pd.to_numeric(s_clean, errors='coerce')
        fail_mask = converted.isna()
        if fail_mask.any():
            bad_examples = df.loc[fail_mask, col].tolist()[:5]
            raise ValueError(f"欄位 [{col}] 發現 {fail_mask.sum()} 筆非數值內容（範例：{bad_examples}），中止轉型！")
        df[col] = converted.astype(float)
        
    # 5. 混合層級互斥分流：子園區明細列 (15筆)、園區合計列 (3筆)、全區總計列 (1筆)
    mask_grand_total = (df['園區別'] == '總計') & (df['子園區'] == '總計')
    mask_park_subtotal = (df['園區別'] != '總計') & (df['子園區'] == '合計')
    mask_subpark_detail = (df['園區別'] != '總計') & (df['子園區'] != '合計')
    
    df_detail = df[mask_subpark_detail].copy().reset_index(drop=True)
    df_subtotal = df[mask_park_subtotal].copy().reset_index(drop=True)
    df_grand_total = df[mask_grand_total].copy().reset_index(drop=True)
    
    # 嚴格驗證分流互斥且筆數總和精確等於原檔
    assert len(df_detail) + len(df_subtotal) + len(df_grand_total) == len(df), "分流筆數總和與原檔不一致！"
    assert not (mask_grand_total & mask_park_subtotal).any(), "總計列與小計列條件重疊！"
```

## 6. 已知限制與外推邊界 (Known Limitations & Caveats)
* **抽樣偏差與涵蓋盲區 (Sampling Bias & Coverage Gaps)**：
  * **僅含「公司法人」總公司登記於園區者，未涵蓋「分公司」或「外國公司在臺辦事處／非公司組織」**（除非曾辦理認許）：部分跨國科技企業或國內大型大廠於科學園區內設立的是「工廠」、「分廠」或「分公司」（例如總公司設於臺北市或新北市，但在竹科或南科設廠營運），若其「公司登記本籍地址」不在園區內，則是否被納入本「公司登記」資料集存在涵蓋盲區【推論待確認】。

## 7. 可執行 Python 防呆載入、代碼串接與分流程式（經實測驗證）

> **環境與依賴說明**：需安裝 `pandas` 及支援讀取舊版 `.xls` 之引擎（如 `xlrd`）。以下程式碼已針對實際檔案 `3大科學園區公司資料集.csv` 與 `公司登記_公司狀態代碼對照表.xls` 實測執行驗證通過：自動處理 UTF-8 BOM、清理 `'備註 '` 尾部空白、保護統編與狀態代碼前置零、自動略過 `.xls` 前 3 列非表頭資訊完成 33 碼對照串接，並執行防呆分流驗證。

```python
import pandas as pd

def load_science_park_companies(csv_path: str, code_xls_path: str = None):
    """
    載入並驗證《3大科學園區公司資料集.csv》 (data.gov.tw/dataset/29277) 與附屬《公司登記_公司狀態代碼對照表.xls》
    保留原檔不改動，保護前置零，清理欄名尾部空白，串接狀態中文說明並執行分流。
    """
    # 1. 嚴格位元組編碼檢測
    with open(csv_path, 'rb') as f:
        raw_bytes = f.read()
    has_bom = raw_bytes.startswith(b'\xef\xbb\xbf')
    
    decoded_text = None
    used_encoding = None
    for enc in ['utf-8-sig', 'utf-8', 'cp950', 'big5']:
        try:
            decoded_text = raw_bytes.decode(enc)
            used_encoding = enc
            break
        except UnicodeDecodeError:
            continue
            
    if decoded_text is None:
        raise ValueError(f"無法以候選編碼 (utf-8-sig, utf-8, cp950, big5) 解碼檔案：{csv_path}")
        
    # 2. 全欄位強制以字串 (str) 讀取，保護「統一編號」與「公司狀態」之前置零不被吞掉
    df_raw = pd.read_csv(csv_path, encoding=used_encoding, dtype=str, keep_default_na=False)
    
    # 3. 清理欄名首尾空白與隱形字元（修正第 5 欄 '備註 ' 之尾部空白）
    orig_cols = list(df_raw.columns)
    clean_cols = [c.replace('\ufeff', '').replace('\u200b', '').strip() for c in orig_cols]
    if len(set(clean_cols)) != len(clean_cols):
        raise ValueError(f"欄名清理後發生重複撞名：{clean_cols}")
    col_mapping = dict(zip(orig_cols, clean_cols))
    
    df = df_raw.copy()
    df.columns = clean_cols
    
    # 4. 驗證主鍵與核心代碼欄位格式（本資料集無數值運算欄位，不強制將識別碼轉數值）
    if (df['統一編號'].str.strip() == '').any():
        raise ValueError("發現空白之『統一編號』紀錄！")
    if df['統一編號'].duplicated().any():
        dup_bans = df.loc[df['統一編號'].duplicated(), '統一編號'].tolist()[:5]
        raise ValueError(f"『統一編號』存在重複值（範例：{dup_bans}）！")
    if not df['公司狀態'].str.match(r'^\d{2}$').all():
        bad_status = df.loc[~df['公司狀態'].str.match(r'^\d{2}$'), '公司狀態'].unique().tolist()
        raise ValueError(f"『公司狀態』存在非 2 位數字格式之異常代碼：{bad_status}")
        
    # 5. 若提供《公司登記_公司狀態代碼對照表.xls》，自動定位第 4 列表頭並進行防呆串接
    if code_xls_path is not None:
        xls = pd.ExcelFile(code_xls_path)
        raw_xls = pd.read_excel(code_xls_path, sheet_name=xls.sheet_names[0], dtype=str, keep_default_na=False)
        
        # 尋找真實表頭列 ('Company_Status')，略過前 3 列標題與製表日期
        header_indices = raw_xls.index[raw_xls.iloc[:, 0].str.strip() == 'Company_Status'].tolist()
        if not header_indices:
            raise ValueError(f"無法在代碼對照表 {code_xls_path} 中定位 'Company_Status' 表頭列！")
        h_idx = header_indices[0]
        
        code_df = raw_xls.iloc[h_idx + 1:, :2].copy()
        code_df.columns = ['Company_Status', 'Company_Status_Desc']
        code_df['Company_Status'] = code_df['Company_Status'].str.strip()
        code_df['Company_Status_Desc'] = code_df['Company_Status_Desc'].str.strip()
        code_df = code_df[code_df['Company_Status'] != ''].reset_index(drop=True)
        
        if code_df['Company_Status'].duplicated().any():
            raise ValueError("代碼對照表中存在重複的 Company_Status 主鍵！")
            
        df = df.merge(code_df, left_on='公司狀態', right_on='Company_Status', how='left')
        unmapped_mask = df['Company_Status_Desc'].isna()
        if unmapped_mask.any():
            bad_codes = df.loc[unmapped_mask, '公司狀態'].unique().tolist()
            raise ValueError(f"主資料集發現無法對應至對照表之公司狀態代碼：{bad_codes}")
            
    # 6. 混合層級與業務狀態互斥分流
    # (a) 檢查是否混入合計/總計彙整列（本檔實測為 0 筆，保留可驗證之空分流）
    mask_summary = df['統一編號'].isin(['合計', '總計', '小計']) | df['公司名稱'].isin(['合計', '總計', '小計'])
    df_summary = df[mask_summary].copy().reset_index(drop=True)
    df_detail = df[~mask_summary].copy().reset_index(drop=True)
    assert len(df_summary) + len(df_detail) == len(df), "彙整列與明細列分流筆數總和與原檔不一致！"
    
    # (b) 將明細依營運狀態分流為「核准設立存續公司 ('01')」與「非正常存續/歷史消滅公司 (其他狀態)」
    mask_active = (df_detail['公司狀態'] == '01')
    df_active = df_detail[mask_active].copy().reset_index(drop=True)
    df_inactive = df_detail[~mask_active].copy().reset_index(drop=True)
    assert len(df_active) + len(df_inactive) == len(df_detail), "營運狀態分流筆數總和與明細筆數不一致！"
    
    print(f"[載入成功] 檔案：{csv_path} | 採用編碼：{used_encoding} (BOM={has_bom})")
    print(f"[欄名清理] 原始欄名對照：{col_mapping}")
    print(f"[分流核對] 原檔總列數={len(df)} | 彙整列(df_summary)={len(df_summary)} | 公司明細(df_detail)={len(df_detail)}")
    print(f"[狀態分流] 核准設立存續公司(df_active, 代碼 '01')={len(df_active)} 筆 | 解散/合併解散/撤銷/廢止等(df_inactive)={len(df_inactive)} 筆")
    return df_detail, df_active, df_inactive, df_summary

if __name__ == '__main__':
    CSV_FILE = '3大科學園區公司資料集.csv'
    XLS_FILE = '公司登記_公司狀態代碼對照表.xls'
    df_detail, df_active, df_inactive, df_summary = load_science_park_companies(CSV_FILE, XLS_FILE)
    # 若需另存串接好狀態說明且清理完欄名之檔案，可取消下方註解（不覆蓋原檔）：
```

## 3. 資料清洗與前處理血統 (Data Lineage & Preprocessing Transformations)
* **【機關端前處理血統】**：
  * **上游原始資料來源**：國科會科學園區廠商投資審議與工商登記統計系統（下載端點為 `mas.nstc.gov.tw/OPENDATA/GetFile?format=csv&serialno=72&fileodr=0`）【官方已說明】。
  * **重複值處理（去重唯一鍵）**：匯出之統計表以 `('園區別', '子園區', '統計項目')` 三欄位組合為唯一識別鍵，全檔 `38` 筆組合完全唯一無重複【檔案觀察】；至於單一企業若同時於多個子園區設廠時，在各子園區與園區合計列中是否分別計數（廠別 vs 法人別去重規則）為【未查得】。
  * **遺漏值（Missing Values）策略**：全檔 `38` 列 × `11` 欄共 `418` 個儲存格中，空字串或 `NULL` 數量均為 `0`。特定子園區於特定產業無廠商進駐者（如新竹生醫園區除生物技術外之 6 個產業欄位），均以整數 `'0'` 填列【檔案觀察】。
  * **異常值與離群值判定**：【不適用】（本表為行政登記廠商家數之精確整數計數）。
  * **特徵轉換、縮放與衍生變數**：
    * **精確整數加總（零尾差）**：所有家數欄位均以「家」為單位之非負整數表示。經 Python 實測驗算，在任一 `統計項目` 下：
      1. **橫向加總**：每一列的前 7 個產業家數相加，**100% 精確等於**該列的 `總計家數`（全檔 38 列橫向差值皆為 `0`）【檔案觀察】。
      2. **縱向加總**：各園區轄下子園區明細相加，**100% 精確等於**該園區之 `合計` 列；三大園區之 `合計` 列相加，**100% 精確等於** `總計` 列（縱向差值皆為 `0`）【檔案觀察】。
  * **去識別化與隱私防護**：本資料集已按「子園區 × 統計項目 × 產業別」聚合為家數計數，不含任何單一企業名稱、統一編號或個人可識別資訊（PII）【檔案觀察】。
  * **前處理程式碼與管線資訊**：【未查得】（機關內部報表產製腳本未公開）。
* **【使用者端前處理血統】**：

## 6. 已知限制與外推邊界 (Known Limitations & Caveats)
* **抽樣偏差與涵蓋盲區 (Sampling Bias & Coverage Gaps)**：
  * **與經濟部《3大科學園區公司資料集》之母體定義差異**：本資料集之「已入區登記廠商家數（全國總計 `1,046` 家）」明確包含**「已辦妥(分)公司登記或工廠登記」**之廠商【官方已說明】；而經濟部商工行政資料開放平臺之《3大科學園區公司資料集》中「核准設立（`01`）」僅有 `807` 家【檔案觀察】。兩者相差 `239` 家之主因在於：許多大型科技企業總公司設於園區外（如臺北、新北），但在科學園區內設立**「分公司」或「工廠（分廠）」**，或同一企業於不同子園區分別設廠登記——這類廠商會計入國科會的「已入區登記廠商家數（`1,046` 家）」，但不會出現在僅收錄總公司本籍登記之商工公司資料集中【官方已說明】【檔案觀察】。
  * **新開發子園區之「核准 vs 入區登記」時間差**：例如南科「橋頭園區」有效核准 `26` 家、已入區登記僅 `3` 家；「楠梓園區」有效核准 `7` 家、已入區登記為 `0` 家；中科「二林園區」有效核准 `38` 家、已入區登記僅 `16` 家【檔案觀察】。這反映新園區廠商通過投資審議後，尚在建廠或環評階段，尚未完成工廠／公司入區登記。
* **前處理帶來的資訊損失 (Information Loss)**：
  * **廠商規模與異質性資訊損失**：所有廠商不論資本額大小（從數千萬元之新創生技公司到數千億元之跨國晶圓製造龍頭）在表中權重皆為 `1 家`【檔案觀察】。
  * **時間維度資訊損失**：檔案內無年份或月份欄位，無法單靠此檔追蹤歷年新核准或撤銷出區之動態變化率【檔案觀察】。
* **外推邊界警告 (Extrapolation Boundaries)**：
  1. **【雙重口徑與合計列重複計算風險 (Severe Double Counting)】 → 絕對不能對全檔 `38` 列直接執行 `SUM()` 或 `MEAN()`**：因為全檔同時混入兩種重疊母體（`有效核准` 包含 `已入區登記`），且各自帶有 `合計` 與 `總計` 列。分析前必須先鎖定單一 `統計項目`（例如只取 `已入區登記廠商家數`），並剔除 `子園區 == '合計'` 與 `園區別 == '總計'` 之彙整列【檔案觀察】。
  2. **【跨表結合計算「平均每家營業額」之分母選擇警告】 → 若與《科學園區產業營業額統計表》結合計算平均每家廠商營業額，分母應優先採用 `已入區登記廠商家數` 而非 `有效核准廠商家數`**：例如楠梓園區「有效核准」有 `7` 家，但「已入區登記」為 `0` 家且營業額為 `0` 億元；橋頭園區「有效核准」有 `26` 家，但「已入區登記」僅 `3` 家（營業額 `0.6` 億元）【檔案觀察】。若誤用尚未入區營運之「有效核准家數」當分母，會嚴重低估開發中園區已營運廠商之平均產出。
  3. **【家數佔比不等於產值佔比】 → 不能從「某產業廠商家數佔比高」推論「該產業為園區營收主力」**：以 `已入區登記廠商家數` 為例，「生物技術」有 `229` 家（佔全區 `1,046` 家的 `21.89%`），「精密機械」有 `234` 家（佔 `22.37%`），兩者家數皆超過「積體電路」的 `220` 家（佔 `21.03%`）【檔案觀察】；但積體電路產業卻貢獻了科學園區 `83.25%` 的總營業額。因此「廠商家數結構」絕對不可外推為「產值結構」或「就業人數結構」。

## 7. 可執行 Python 防呆載入與分流程式（經實測驗證）

> **環境與依賴說明**：需安裝 `pandas`（Python 3.8+）。以下程式碼已針對實際檔案 `國家科學及技術委員會科學園區產業類別及家數統計.csv` 實測執行驗證通過，自動處理 BOM、檢查整數轉型，並同時完成「地理層級三層分流」與「兩種統計項目口徑分流」。

```python
import pandas as pd

def load_nstc_science_park_company_counts(csv_path: str):
    """
    載入並驗證《國家科學及技術委員會科學園區產業類別及家數統計.csv》 (data.gov.tw/dataset/7596)
    保留原檔不改動，於記憶體副本執行欄名清理、安全整數轉型，以及「統計項目 × 地理彙整層級」雙重分流。
    """
    # 1. 嚴格位元組編碼檢測
    with open(csv_path, 'rb') as f:
        raw_bytes = f.read()
    has_bom = raw_bytes.startswith(b'\xef\xbb\xbf')
    
    decoded_text = None
    used_encoding = None
    for enc in ['utf-8-sig', 'utf-8', 'cp950', 'big5']:
        try:
            decoded_text = raw_bytes.decode(enc)
            used_encoding = enc
            break
        except UnicodeDecodeError:
            continue
            
    if decoded_text is None:
        raise ValueError(f"無法以候選編碼 (utf-8-sig, utf-8, cp950, big5) 解碼檔案：{csv_path}")
        
    # 2. 初始以純字串讀取，關閉預設 NA 解析
    df_raw = pd.read_csv(csv_path, encoding=used_encoding, dtype=str, keep_default_na=False)
    
    # 3. 清理欄名首尾空白與隱形字元，並防範撞名
    orig_cols = list(df_raw.columns)
    clean_cols = [c.replace('\ufeff', '').replace('\u200b', '').strip() for c in orig_cols]
    if len(set(clean_cols)) != len(clean_cols):
        raise ValueError(f"欄名清理後發生重複撞名：{clean_cols}")
        
    df = df_raw.copy()
    df.columns = clean_cols
    
    # 4. 針對已確認之整數欄位進行安全轉型（分開檢查原始空值與轉型失敗）
    int_cols = [
        '積體電路(家)', '光電(家)', '電腦及周邊(家)', '通訊(家)',
        '精密機械(家)', '生物技術(家)', '其他家數', '總計家數'
    ]
    for col in int_cols:
        if col not in df.columns:
            raise KeyError(f"缺少預期整數欄位：{col}")
        s_clean = df[col].str.strip().str.replace(',', '', regex=False)
        empty_mask = (s_clean == '')
        if empty_mask.any():
            raise ValueError(f"欄位 [{col}] 發現 {empty_mask.sum()} 筆原始空值，中止轉型！")
        converted = pd.to_numeric(s_clean, errors='coerce')
        fail_mask = converted.isna() | (converted % 1 != 0)
        if fail_mask.any():
            bad_examples = df.loc[fail_mask, col].tolist()[:5]
            raise ValueError(f"欄位 [{col}] 發現 {fail_mask.sum()} 筆非整數內容（範例：{bad_examples}），中止轉型！")
        df[col] = converted.astype('int64')
        
    # 5. 第一重分流：依地理彙整層級切分（子園區明細 30 筆、園區合計 6 筆、全區總計 2 筆）
    mask_grand_total = (df['園區別'] == '總計') & (df['子園區'] == '總計')
    mask_park_subtotal = (df['園區別'] != '總計') & (df['子園區'] == '合計')
    mask_subpark_detail = (df['園區別'] != '總計') & (df['子園區'] != '合計')
    
    df_detail = df[mask_subpark_detail].copy().reset_index(drop=True)
    df_subtotal = df[mask_park_subtotal].copy().reset_index(drop=True)
    df_grand_total = df[mask_grand_total].copy().reset_index(drop=True)
    
    assert len(df_detail) + len(df_subtotal) + len(df_grand_total) == len(df), "地理層級分流筆數總和與原檔不一致！"
    assert not (mask_grand_total & mask_park_subtotal).any(), "總計列與小計列條件重疊！"
    assert not (mask_grand_total & mask_subpark_detail).any(), "總計列與明細列條件重疊！"
    assert not (mask_park_subtotal & mask_subpark_detail).any(), "小計列與明細列條件重疊！"
    
    # 6. 第二重分流：將子園區明細依「統計項目」切分為兩張獨立乾淨明細表（各 15 筆）
    df_detail_approved = df_detail[df_detail['統計項目'] == '有效核准廠商家數'].copy().reset_index(drop=True)
    df_detail_registered = df_detail[df_detail['統計項目'] == '已入區登記廠商家數'].copy().reset_index(drop=True)
    assert len(df_detail_approved) + len(df_detail_registered) == len(df_detail), "存在未知的『統計項目』類別！"
    
    print(f"[載入成功] 檔案：{csv_path} | 採用編碼：{used_encoding} (BOM={has_bom})")
    print(f"[層級分流] 原檔總列數={len(df)} | 子園區明細(df_detail)={len(df_detail)} | 園區合計(df_subtotal)={len(df_subtotal)} | 全區總計(df_grand_total)={len(df_grand_total)}")
    print(f"[口徑分流] 有效核准子園區明細={len(df_detail_approved)} 筆 (總和={df_detail_approved['總計家數'].sum()} 家) | 已入區登記子園區明細={len(df_detail_registered)} 筆 (總和={df_detail_registered['總計家數'].sum()} 家)")
    return df_detail_approved, df_detail_registered, df_subtotal, df_grand_total

if __name__ == '__main__':
    CSV_FILE = '國家科學及技術委員會科學園區產業類別及家數統計.csv'
    df_approved, df_registered, df_subtotal, df_grand_total = load_nstc_science_park_company_counts(CSV_FILE)
```

## 2. 資料蒐集方法 (Data Collection Methodology)
* **目標母體與抽樣邊界**：

## 3. 資料清洗與前處理血統 (Data Lineage & Preprocessing Transformations)
* **【機關端前處理血統】**：
  * **上游原始資料來源**：國科會科學園區從業員工統計系統（下載端點為 `mas.nstc.gov.tw/OPENDATA/GetFile?format=csv&serialno=75&fileodr=0`）【官方已說明】。
  * **重複值處理（去重唯一鍵）**：匯出之統計表以 `('園區別', '子園區')` 雙欄位組合為唯一識別鍵，全檔 `19` 筆組合完全唯一無重複【檔案觀察】；至於機關端對上游員工跨區調動或兼職之去重規則為【未查得】。
  * **遺漏值（Missing Values）策略**：全檔 `19` 列 × `9` 欄共 `171` 個儲存格中，空字串或 `NULL` 數量均為 `0`。楠梓園區因尚無已入區登記廠商（參照 `dataset/7596`），其各學歷欄位與總人數均以整數 `'0'` 填列【檔案觀察】。
  * **異常值與離群值判定**：【不適用】（本表為行政申報人數之精確整數計數）。
  * **特徵轉換、縮放與衍生變數**：
    * **精確整數加總（零尾差）**：所有欄位均以「人」為單位之非負整數表示。經 Python 實測驗算：
      1. **橫向加總**：每一列的 6 個學歷欄位（`博士(人)` + `碩士(人)` + `大學(人)` + `專科(人)` + `高中(人)` + `其他(人)`）相加，**100% 精確等於**該列的 `總人數`（全檔 19 列橫向差值皆為 `0`）【檔案觀察】。
      2. **縱向加總**：各園區轄下子園區明細相加，**100% 精確等於**該園區之 `合計` 列；三大園區之 `合計` 列相加，**100% 精確等於** `總計` 列（縱向差值皆為 `0`）【檔案觀察】。
  * **去識別化與隱私防護**：本資料集已按「子園區 × 教育程度」高度聚合為人數總和，不含任何自然人姓名、身分證字號、薪資或個人可識別資訊（PII）【檔案觀察】。
  * **前處理程式碼與管線資訊**：【未查得】（機關內部報表產製腳本未公開）。
* **【使用者端前處理血統】**：
  * **檔案取得與原檔狀態**：由使用者自政府資料開放平臺（`dataset/7599`）下載並提供本地檔案 `國家科學及技術委員會科學園區從業員工數統計.csv`，**原始檔案保持唯讀未改動**【檔案觀察】。
  * **讀取與檢查操作**：於分析環境透過 Python（`pandas` 套件）以 `encoding='utf-8-sig', dtype=str, keep_default_na=False` 讀取全部 `19` 列，執行欄名空白與 BOM 檢查、整數轉型測試、橫縱向加總零誤差驗算，並將資料分流為 `df_detail`（15 筆）、`df_subtotal`（3 筆）與 `df_grand_total`（1 筆）三個獨立資料框副本【檔案觀察】。

## 6. 已知限制與外推邊界 (Known Limitations & Caveats)
* **抽樣偏差與涵蓋盲區 (Sampling Bias & Coverage Gaps)**：
  * **排除營造廠與承攬商僱用人員**：依官方定義，本資料集**不包括營造廠或承攬商所僱用之員工數**【官方已說明】。因此，在正值大規模擴建廠房之子園區（如南科楠梓園區、橋頭園區、竹科寶山／銅鑼園區、中科二林園區），現場實際每日進出之工程營造與設備裝機承攬人員可能高達數千至數萬人，但在本表中楠梓園區顯示為 `0` 人、橋頭園區僅 `55` 人【檔案觀察】。
  * **包含非科技製造業之園區機構人員**：母體除了「園區事業（科技廠商）」外，亦包含「核准入區工商服務業、事業主管機關分支單位（如園區管理局）、育成中心、研究機構」之員工數【官方已說明】。
* **前處理帶來的資訊損失 (Information Loss)**：
  * **缺乏「產業別 × 學歷」交叉維度**：本檔僅按「子園區 × 教育程度」彙總，未提供「各產業別（如積體電路 vs 光電 vs 生技）」之從業員工數，無法單靠此檔計算單一產業的人均產值【檔案觀察】。
  * **缺乏性別、年齡、國籍（本國籍 vs 外籍移工／白領）與職類維度**：無法區分研發工程師、行政人員與產線技術員／外籍移工之比例【檔案觀察】。
* **外推邊界警告 (Extrapolation Boundaries)**：
  1. **【合計列重複計算風險 (Double Counting)】 → 絕對不能對全檔 `19` 列直接執行 `SUM()` 或 `MEAN()`**：因為第 7、13、18 列為三大園區之「合計」列，第 19 列為全區「總計」列。若分析時未先剔除這 4 列彙整列，總人數會被算成 `984,477` 人，恰為真實總人數 `328,159` 人的 **3 倍**【檔案觀察】。
  2. **【跨表計算「人均營業額」之分子分母口徑不對稱警告】 → 當結合《科學園區產業營業額統計表》與本表計算各子園區「人均營業額」時，需注意分母略大於純園區廠商員工數**：因為營業額（分子）僅計入「園區廠商之銷售淨額」【官方已說明】（`dataset/7597`），而本表從業員工數（分母）除了園區廠商外，還包含了**園區管理局分支單位、研究機構、育成中心與工商服務業之員工**【官方已說明】（`dataset/7599`）。在廠商密集的大園區（如新竹園區 `149,421` 人、臺南園區 `78,763` 人）影響極微，但在以研究機構、育成或行政單位為主的新設小園區（如中興園區 `925` 人、宜蘭園區 `668` 人），會使計算出之人均園區事業營業額略微偏低【檔案觀察】【官方已說明】。
  3. **【通勤與日夜間人口推估限制】 → 不能以本表人數直接外推開發中子園區之「施工期交通衝擊或外食需求」**：由於本表完全排除營造廠與承攬商人員【官方已說明】，對楠梓園區（帳面 `0` 人）或橋頭園區（帳面 `55` 人）進行交通流量或周邊生活機能評估時，絕對不可誤以為現場無工作人口進出。

## 7. 可執行 Python 防呆載入與分流程式（經實測驗證）

> **環境與依賴說明**：需安裝 `pandas`（Python 3.8+）。以下程式碼已針對實際檔案 `國家科學及技術委員會科學園區從業員工數統計.csv` 實測執行驗證通過，確認無欄名撞名、無整數轉型失敗，且三層分流（15 筆明細 + 3 筆合計 + 1 筆總計 = 19 筆）完全互斥吻合。

```python
import pandas as pd

def load_nstc_science_park_employees(csv_path: str):
    """
    載入並驗證《國家科學及技術委員會科學園區從業員工數統計.csv》 (data.gov.tw/dataset/7599)
    保留原檔不改動，於記憶體副本執行欄名清理、安全整數轉型與三層彙整分流。
    """
    # 1. 嚴格位元組編碼檢測
    with open(csv_path, 'rb') as f:
        raw_bytes = f.read()
    has_bom = raw_bytes.startswith(b'\xef\xbb\xbf')
    
    decoded_text = None
    used_encoding = None
    for enc in ['utf-8-sig', 'utf-8', 'cp950', 'big5']:
        try:
            decoded_text = raw_bytes.decode(enc)
            used_encoding = enc
            break
        except UnicodeDecodeError:
            continue
            
    if decoded_text is None:
        raise ValueError(f"無法以候選編碼 (utf-8-sig, utf-8, cp950, big5) 解碼檔案：{csv_path}")
        
    # 2. 初始以純字串讀取，關閉預設 NA 解析
    df_raw = pd.read_csv(csv_path, encoding=used_encoding, dtype=str, keep_default_na=False)
    
    # 3. 清理欄名首尾空白與隱形字元，並防範撞名
    orig_cols = list(df_raw.columns)
    clean_cols = [c.replace('\ufeff', '').replace('\u200b', '').strip() for c in orig_cols]
    if len(set(clean_cols)) != len(clean_cols):
        raise ValueError(f"欄名清理後發生重複撞名：{clean_cols}")
        
    df = df_raw.copy()
    df.columns = clean_cols
    
    # 4. 針對已確認之整數欄位進行安全轉型（分開檢查原始空值與轉型失敗）
    int_cols = ['博士(人)', '碩士(人)', '大學(人)', '專科(人)', '高中(人)', '其他(人)', '總人數']
    for col in int_cols:
        if col not in df.columns:
            raise KeyError(f"缺少預期整數欄位：{col}")
        s_clean = df[col].str.strip().str.replace(',', '', regex=False)
        empty_mask = (s_clean == '')
        if empty_mask.any():
            raise ValueError(f"欄位 [{col}] 發現 {empty_mask.sum()} 筆原始空值，中止轉型！")
        converted = pd.to_numeric(s_clean, errors='coerce')
        fail_mask = converted.isna() | (converted % 1 != 0)
        if fail_mask.any():
            bad_examples = df.loc[fail_mask, col].tolist()[:5]
            raise ValueError(f"欄位 [{col}] 發現 {fail_mask.sum()} 筆非整數內容（範例：{bad_examples}），中止轉型！")
        df[col] = converted.astype('int64')
        
    # 5. 混合層級互斥分流：子園區明細列 (15筆)、園區合計列 (3筆)、全區總計列 (1筆)
    mask_grand_total = (df['園區別'] == '總計') & (df['子園區'] == '總計')
    mask_park_subtotal = (df['園區別'] != '總計') & (df['子園區'] == '合計')
    mask_subpark_detail = (df['園區別'] != '總計') & (df['子園區'] != '合計')
    
    df_detail = df[mask_subpark_detail].copy().reset_index(drop=True)
    df_subtotal = df[mask_park_subtotal].copy().reset_index(drop=True)
    df_grand_total = df[mask_grand_total].copy().reset_index(drop=True)
    
    assert len(df_detail) + len(df_subtotal) + len(df_grand_total) == len(df), "分流筆數總和與原檔不一致！"
    assert not (mask_grand_total & mask_park_subtotal).any(), "總計列與小計列條件重疊！"
    assert not (mask_grand_total & mask_subpark_detail).any(), "總計列與明細列條件重疊！"
    assert not (mask_park_subtotal & mask_subpark_detail).any(), "小計列與明細列條件重疊！"
    
    print(f"[載入成功] 檔案：{csv_path} | 採用編碼：{used_encoding} (BOM={has_bom})")
    print(f"[分流核對] 原檔總列數={len(df)} | 子園區明細(df_detail)={len(df_detail)} | 園區合計(df_subtotal)={len(df_subtotal)} | 全區總計(df_grand_total)={len(df_grand_total)}")
    print(f"[人數核對] 15 個子園區明細加總={df_detail['總人數'].sum():,} 人 | 全區總計列={df_grand_total['總人數'].iloc[0]:,} 人")
    return df_detail, df_subtotal, df_grand_total

if __name__ == '__main__':
    CSV_FILE = '國家科學及技術委員會科學園區從業員工數統計.csv'
    df_detail, df_subtotal, df_grand_total = load_nstc_science_park_employees(CSV_FILE)
```

  * **遺漏值（Missing Values）策略**：
    * 全檔 `32` 列 × `11` 欄共 `352` 個儲存格中，有 **`1` 個儲存格為空字串 `''`**：位於第 12 列（`園區別='中部科學園區', 產業別='通訊'`）的第 5 欄 `出口額成長率(％)`【檔案觀察】。
    * **遺漏原因證據**：該列之 `出口額(113年)(億元)` 為 `'0'`、`出口額(114年)(億元)` 亦為 `'0'`。因成長率計算公式為 $\frac{\text{114年} - \text{113年}}{\text{113年}} \times 100\%$，當 113 年基期為 $0$ 時分母為零無意義，故機關端以空字串 `''` 留白【檔案觀察】。
  * **異常值與離群值判定**：統計上存在極端高成長率數值（屬真實貿易變動而非資料錯誤）——例如南科「其他」產業之進口額由 113 年 `1.59` 億元增至 114 年 `20.22` 億元，**進口額成長率高達 `1171.63％`**（貿易總額成長率 `420.66％`）；南科「電腦及周邊」114 年出口額成長率亦達 `277.38％`【檔案觀察】。依規範**統計離群不等於資料錯誤，絕不自動刪除**。
  * **特徵轉換、縮放與衍生變數**：
    * **衍生欄位公式 1（貿易總額）**：`貿易總額 = 出口額 + 進口額`【官方已說明】。經 Python 驗算，因機關端係以未四捨五入之原始金額相加後再四捨五入至小數點後 2 位，全檔 32 列中有少數列與帳面直加存在 $\pm 0.01$ 億元之正常四捨五入尾差（例如 113 年有 3 列、114 年有 11 列差 $\pm 0.01$ 億元）【檔案觀察】。
    * **衍生欄位公式 2（成長率 `％`）**：$\text{成長率(％)} = \frac{\text{114年金額} - \text{113年金額}}{\text{113年金額}} \times 100\%$。同樣因上游以原始未四捨五入金額計算成長率，與用帳面四捨五入至億元後之數值重算相比，在基期金額較小的列會有些微尾差（例如中科「其他」113 年進口額帳面 `0.15` 億元、114 年 `0.19` 億元，帳面重算為 `26.67%`，原表由精確值算出為 `24.83%`）【檔案觀察】。
  * **去識別化與隱私防護**：本資料集已按「園區別 × 產業別」高度聚合，不含任何單一企業名稱、統一編號或個人可識別資訊（PII）【檔案觀察】。

## 6. 已知限制與外推邊界 (Known Limitations & Caveats)
* **抽樣偏差與涵蓋盲區 (Sampling Bias & Coverage Gaps)**：
  * **僅涵蓋「園區レベル（三大園區）」與「產業別」，無「15 個子園區」細目**：與營業額（`7597`）、家數（`7596`）、員工數（`7599`）不同，本進出口資料集僅按「新竹科學園區、中部科學園區、南部科學園區」三大園區統計，**未拆分至 15 個子園區**【檔案觀察】。
  * **進出口報關額不等於園區營業額（內銷與三角貿易差異）**：例如 114 年全國科學園區總營業額為 `58,010.23` 億元（見 `dataset/7597`），而本表 114 年全國科學園區總出口額為 `46,356.39` 億元【檔案觀察】。兩者差額反映園區廠商之「國內銷售（內銷予國內下游客戶或園區內同業轉廠交易）」以及計價時點（報關日 vs 發票申報期）與匯率換算差異。
* **前處理帶來的資訊損失 (Information Loss)**：
  * **`園區別 == '總計'` 區塊之產業合併損失**：如第 2 節所述，在 `園區別 == '總計'` 區塊中，官方未單獨列出「通訊」、「精密機械」、「生物技術」三列，而是將其全數併入第 31 列 `園區別='總計', 產業別='其他'`（114 年貿易總額 `2,879.05` 億元）【檔案觀察】。若使用者直接查看 `園區別 == '總計'` 的子表，會誤以為全國科學園區沒有通訊、精密機械、生技產業的進出口數據，或誤以為「其他產業」貿易額高達 `2,879.05` 億元（實際上三大園區真正的「其他產業」114 年貿易總額相加僅為 `73.75 + 28.43 + 47.41 = 149.59` 億元）【檔案觀察】！
  * **缺乏貿易對手國（地區）與月度／季度時間維度**：無法單靠本表得知對美、對中、對歐日韓之出口比重或季節性波動【檔案觀察】。
* **外推邊界警告 (Extrapolation Boundaries)**：
  1. **【四層彙整列重複計算與比率誤加風險】 → 絕對不能對全檔 `32` 列直接加總金額，且在任何情況下都不可將 `成長率(％)` 欄位相加或取簡單算術平均**：加總金額時必須僅取 `24` 筆園區產業明細列（否則總貿易額會被重複加總 3 倍）；而計算跨園區或跨產業之合計成長率時，**必須先加總 113 年金額與 114 年金額，再以 $\frac{\sum \text{114年} - \sum \text{113年}}{\sum \text{113年}} \times 100\%$ 重新計算加權成長率**【檔案觀察】。
  2. **【`總計` 區塊之「其他」語義不一致陷阱】 → 絕對不能拿第 31 列（`園區別='總計', 產業別='其他'`）與各園區的 `產業別='其他'` 直接比較或求佔比**：因為第 31 列實際上是 `通訊 + 精密機械 + 生物技術 + 其他` 四個產業的全國總和！若要取得全國「通訊」、「精密機械」、「生物技術」或真正「其他」產業的進出口總額，必須從 `24` 筆園區明細列中按 `產業別` 自行跨園區加總【檔案觀察】。
  3. **【高進口額成長率之經濟解讀邊界】 → 不能將「進口額大幅增長（或特定產業貿易逆差）」直接外推為「產業競爭力衰退」**：科學園區（特別是積體電路產業，114 年進口額成長 `45.32％` 達 `29,482.58` 億元）之進口主力包含高價先進半導體製程設備（如 EUV 曝光機）與關鍵原物料【檔案觀察】。進口額大增往往代表廠商正積極擴充先進產能與資本支出，而非消費性貿易逆差。

## 7. 可執行 Python 防呆載入與分流程式（經實測驗證）

> **環境與依賴說明**：需安裝 `pandas` 與 `numpy`（Python 3.8+）。以下程式碼已針對實際檔案 `國家科學及技術委員會科學園區進出口情形.csv` 實測執行驗證通過：自動處理 BOM、**按位置索引修正 3 個同名 `'成長率(％)'` 欄位**、**安全處理中科通訊出口成長率之除零空字串（轉為 `np.nan`）**，並完成四層彙整結構之互斥分流驗證。

```python
import csv
import numpy as np
import pandas as pd

def load_nstc_science_park_trade(csv_path: str):
    """
    載入並驗證《國家科學及技術委員會科學園區進出口情形.csv》 (data.gov.tw/dataset/7598)
    保留原檔不改動，解決 3 個同名『成長率(％)』欄名碰撞問題、處理除零空值，並執行四層互斥分流。
    """
    # 1. 嚴格位元組編碼檢測
    with open(csv_path, 'rb') as f:
        raw_bytes = f.read()
    has_bom = raw_bytes.startswith(b'\xef\xbb\xbf')
    
    decoded_text = None
    used_encoding = None
    for enc in ['utf-8-sig', 'utf-8', 'cp950', 'big5']:
        try:
            decoded_text = raw_bytes.decode(enc)
            used_encoding = enc
            break
        except UnicodeDecodeError:
            continue
            
    if decoded_text is None:
        raise ValueError(f"無法以候選編碼 (utf-8-sig, utf-8, cp950, big5) 解碼檔案：{csv_path}")
        
    # 2. 使用 csv.reader 讀取原始表頭與資料列，以攔截並處理原始表頭中的同名欄位 ('成長率(％)' 出現 3 次)
    lines = decoded_text.splitlines()
    reader = list(csv.reader(lines))
    raw_header = [c.replace('\ufeff', '').replace('\u200b', '').strip() for c in reader[0]]
    data_rows = reader[1:]
    
    expected_raw_header = [
        '園區別', '產業別',
        '出口額(113年)(億元)', '出口額(114年)(億元)', '成長率(％)',
        '進口額(113年)(億元)', '進口額(114年)(億元)', '成長率(％)',
        '貿易總額(113年)(億元)', '貿易總額(114年)(億元)', '成長率(％)'
    ]
    if raw_header != expected_raw_header:
        raise ValueError(f"原始表頭結構與預期不符：{raw_header}")
        
    # 按欄位位置賦予唯一且語義明確之欄位名稱，徹底消除同名覆蓋或 .1/.2 混淆
    unique_cols = [
        '園區別', '產業別',
        '出口額(113年)(億元)', '出口額(114年)(億元)', '出口額成長率(％)',
        '進口額(113年)(億元)', '進口額(114年)(億元)', '進口額成長率(％)',
        '貿易總額(113年)(億元)', '貿易總額(114年)(億元)', '貿易總額成長率(％)'
    ]
    df = pd.DataFrame(data_rows, columns=unique_cols, dtype=str)
    
    # 3. 數值欄位安全轉型（區分「金額欄位：不可為空」與「成長率欄位：允許基期為 0 時之原始空字串轉 NaN」）
    amount_cols = [
        '出口額(113年)(億元)', '出口額(114年)(億元)',
        '進口額(113年)(億元)', '進口額(114年)(億元)',
        '貿易總額(113年)(億元)', '貿易總額(114年)(億元)'
    ]
    rate_cols = ['出口額成長率(％)', '進口額成長率(％)', '貿易總額成長率(％)']
    
    for col in amount_cols:
        s_clean = df[col].str.strip().str.replace(',', '', regex=False)
        if (s_clean == '').any():
            raise ValueError(f"金額欄位 [{col}] 發現原始空值，中止轉型！")
        converted = pd.to_numeric(s_clean, errors='coerce')
        if converted.isna().any():
            bad_vals = df.loc[converted.isna(), col].tolist()[:5]
            raise ValueError(f"金額欄位 [{col}] 發現非數值內容：{bad_vals}")
        df[col] = converted.astype(float)
        
    for col in rate_cols:
        s_clean = df[col].str.strip().str.replace(',', '', regex=False)
        empty_mask = (s_clean == '')
        converted = pd.to_numeric(s_clean, errors='coerce')
        # 嚴格區分「原始即為空字串（因基期為0）」與「非空字串但轉型失敗」
        invalid_str_mask = (~empty_mask) & converted.isna()
        if invalid_str_mask.any():
            bad_vals = df.loc[invalid_str_mask, col].tolist()[:5]
            raise ValueError(f"成長率欄位 [{col}] 發現無法轉為數值之異常文字：{bad_vals}")
        df[col] = converted.astype(float)  # 原始空字串安全轉為 np.nan
        
    # 4. 四層混合彙整結構互斥分流
    # 層級 1: 三大園區 × 7 產業明細列 (24筆)
    mask_detail = (df['園區別'] != '總計') & (df['產業別'] != '合計')
    # 層級 2: 三大園區小計列 (3筆: 園區別 != '總計' 且 產業別 == '合計')
    mask_park_subtotal = (df['園區別'] != '總計') & (df['產業別'] == '合計')
    # 層級 3: 全區按產業小計列 (4筆: 園區別 == '總計' 且 產業別 != '總計'；注意其中的『其他』含通訊+精密機械+生技+其他)
    mask_national_by_ind = (df['園區別'] == '總計') & (df['產業別'] != '總計')
    # 層級 4: 全區總計列 (1筆: 園區別 == '總計' 且 產業別 == '總計')
    mask_grand_total = (df['園區別'] == '總計') & (df['產業別'] == '總計')
    
    df_detail = df[mask_detail].copy().reset_index(drop=True)
    df_park_subtotal = df[mask_park_subtotal].copy().reset_index(drop=True)
    df_national_by_ind = df[mask_national_by_ind].copy().reset_index(drop=True)
    df_grand_total = df[mask_grand_total].copy().reset_index(drop=True)
    
    assert len(df_detail) + len(df_park_subtotal) + len(df_national_by_ind) + len(df_grand_total) == len(df), "四層分流筆數總和與原檔不一致！"
    
    print(f"[載入成功] 檔案：{csv_path} | 採用編碼：{used_encoding} (BOM={has_bom})")
    print(f"[欄名修正] 已將 3 個重複的『成長率(％)』依位置重新命名為：{rate_cols}")
    print(f"[分流核對] 原檔總列數={len(df)} | 園區產業明細(df_detail)={len(df_detail)} | 園區合計(df_park_subtotal)={len(df_park_subtotal)} | 全國產業小計(df_national_by_ind)={len(df_national_by_ind)} | 全區總計(df_grand_total)={len(df_grand_total)}")
    return df_detail, df_park_subtotal, df_national_by_ind, df_grand_total

if __name__ == '__main__':
    CSV_FILE = '國家科學及技術委員會科學園區進出口情形.csv'
    df_detail, df_park_subtotal, df_national_by_ind, df_grand_total = load_nstc_science_park_trade(CSV_FILE)
```
