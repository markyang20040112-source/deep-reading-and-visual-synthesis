## 2. 資料蒐集方法 (Data Collection Methodology)
* **目標母體與抽樣邊界**：
  * **母體定義**：國家科學及技術委員會轄下三大科學園區（新竹科學園區、中部科學園區、南部科學園區）內所有已入區營運並申報銷售額之園區廠商【官方已說明】。
  * **地理與園區邊界**：涵蓋三大科學園區共 15 個子園區——竹科（新竹、竹南、龍潭、新竹生醫、銅鑼、宜蘭）、中科（台中、虎尾、后里、二林、中興）、南科（臺南、高雄、橋頭、楠梓）【檔案觀察】。
  * **抽樣機制**：母體普查／全量廠商申報書彙整（非抽樣調查；平臺標示「資料集上架方式：原始資料」）【官方已說明】（依 `dataset/7597` 描述，係由園區廠商之申報書銷售額、收據合計等核算彙總）。
* **蒐集工具與管道**：
  * **原始管道**：依據園區廠商營業稅申報書銷售額、收據合計、銷貨退回及折讓、前期銷售額調整，扣除代收代付、出售固定資產、出售廢料、利息收入、樣品贈送等可抵減項目後，由各科學園區管理局與國科會彙整產製【官方已說明】（引自 https://data.gov.tw/dataset/7597 ）。
  * **人工介入與二次轉譯**：【未查得】（未知機關端於廠商申報資料異常或跨期調整時之人工稽核流程）。
* **時間範圍與取樣頻率**：
  * **記錄起迄時間**：`2025-01-01` 至 `2025-12-31`（2025 全年度累計值）【推論待確認】（依數值與國科會 2025 年營運記者會數據比對推論）。
  * **取樣與更新頻率**：**不定期更新**【官方已說明】（引自 https://data.gov.tw/dataset/7597 「更新頻率：不定期更新」）。
  * **資料性質**：單一統計期間之橫斷面彙整快照（Cross-sectional Aggregated Snapshot），不含時間序列維度欄位【檔案觀察】。
* **混合層級與彙整列觀察**：
  * 本檔共 `19` 筆資料列，明確存在**三種互斥的資料彙整層級**【檔案觀察】：
    1. **子園區明細列（共 `15` 筆）**：第 1～6 列（竹科 6 子園區）、第 8～12 列（中科 5 子園區）、第 14～17 列（南科 4 子園區）。
    2. **園區小計列（共 `3` 筆，`子園區 == '合計'`）**：第 7 列（`園區別='新竹科學園區', 子園區='合計'`）、第 13 列（`園區別='中部科學園區', 子園區='合計'`）、第 18 列（`園區別='南部科學園區', 子園區='合計'`）。
    3. **全區總計列（共 `1` 筆，`園區別 == '總計'` 且 `子園區 == '總計'`）**：第 19 列。
  * 類別欄位中包含已命名之「其他」彙總欄位：`其他產業營業額(億元)`，係作為六大核心產業以外之園區廠商營業額加總【檔案觀察】。

## 3. 資料清洗與前處理血統 (Data Lineage & Preprocessing Transformations)
* **【機關端前處理血統】**：
  * **上游原始資料來源**：國科會科學園區廠商營運／銷售額申報統計系統（下載端點為 `mas.nstc.gov.tw/OPENDATA/GetFile?format=csv&serialno=73&fileodr=0`）【官方已說明】。
  * **重複值處理（去重唯一鍵）**：匯出之統計表以 `('園區別', '子園區')` 雙欄位組合為唯一識別鍵，全檔 `19` 筆組合完全唯一無重複【檔案觀察】；至於機關端對上游廠商申報明細去重之規則為【未查得】。
  * **遺漏值（Missing Values）策略**：全檔 `19` 列 × `10` 欄共 `190` 個儲存格中，空字串或 `NULL` 數量均為 `0`。部分子園區於特定產業無營業額者（如楠梓園區全部產業、橋頭園區除積體電路外之產業、新竹生醫園區除生物技術外之產業），均以數值 `'0'` 填列【檔案觀察】。
  * **異常值與離群值判定**：【未查得】（機關端是否對個別廠商極端申報值進行人工查核未見說明）。
  * **特徵轉換、縮放與衍生變數**：
    * **銷售淨額核算公式**：`營業額 = 銷售淨額（含申報書銷售額 + 收據合計 - 銷貨退回及折讓 ± 前期銷售額調整） - 可抵減項目（代收代付 + 出售固定資產 + 出售廢料 + 利息收入 + 樣品贈送）`【官方已說明】（引自 https://data.gov.tw/dataset/7597 ）。
    * **單位縮放與四捨五入**：所有金額欄位均縮放以「新臺幣億元」為單位，並四捨五入保留至小數點後第 2 位（尾數為 `.00` 或 `.x0` 者在 CSV 中省略尾零，如 `'0'`, `'12881.3'`, `'29705.4'`）【檔案觀察】。
    * **衍生小計／總計與尾差現象**：經 Python 實測核對，機關端之「合計」與「總計」並非以本表四捨五入後之小數直接相加，而是以**上游未四捨五入之原始精確金額加總後再各自四捨五入**【檔案觀察】【推論待確認】。因此本檔內存在 $\pm 0.01$ 億元之正常四捨五入尾差（Rounding Discrepancy）：
      * **橫向加總尾差（7 項產業相加 vs `總計營業額(億元)`）**：`竹南園區`（橫向和 `564.71` vs 總計欄 `564.72`，差 `-0.01`）、`龍潭園區`（橫向和 `315.29` vs 總計欄 `315.28`，差 `+0.01`）、`宜蘭園區`（橫向和 `14.57` vs 總計欄 `14.56`，差 `+0.01`）、`虎尾園區`（橫向和 `57.44` vs 總計欄 `57.45`，差 `-0.01`）【檔案觀察】。
      * **縱向加總尾差（子園區相加 vs 園區`合計`列）**：竹科之積體電路（子園區和 `12881.29` vs 合計列 `12881.3`）、電腦及周邊（`1241.13` vs `1241.12`）、精密機械（`675.29` vs `675.28`）；中科之積體電路（`9419.61` vs `9419.6`）、光電（`1211.72` vs `1211.73`）、其他產業（`53.16` vs `53.17`）均差 $\pm 0.01$ 億元【檔案觀察】。
      * **全區總計尾差（3 園區`合計`相加 vs `總計`列）**：積體電路（`48292.64` vs `48292.63`）、通訊（`645.75` vs `645.76`）、精密機械（`1808.25` vs `1808.26`）、其他產業（`294.40` vs `294.39`）均差 $\pm 0.01$ 億元【檔案觀察】。
  * **去識別化與隱私防護**：本資料集已按「子園區 × 產業別」高度聚合（Aggregation），不含任何單一企業名稱、統一編號或個人可識別資訊（PII）【檔案觀察】。

## 6. 已知限制與外推邊界 (Known Limitations & Caveats)
* **抽樣偏差與涵蓋盲區 (Sampling Bias & Coverage Gaps)**：
  * **僅涵蓋國科會轄下三大科學園區入區廠商**：未進入科學園區設廠之高科技企業（例如位於經濟部產業園區／加工出口區、地方政府工業區或一般都市計畫區之 IC 設計、光電、生技、機械廠商），其營業額均不在本資料集涵蓋範圍內【檔案觀察】【官方已說明】。
  * **新設／開發中園區之零值現象**：例如南部科學園區之「楠梓園區」各產業營業額均為 `0`，橋頭園區僅積體電路產業有 `0.6` 億元【檔案觀察】。這反映特定子園區於該統計年度尚處於建廠或初期營運階段，不代表該地區無相關投資或產業活動。
* **前處理帶來的資訊損失 (Information Loss)**：
  * **廠商個體分布資訊完全損失**：資料已按「子園區 × 產業別」聚合為單一總和，無法得知各子園區內之廠商總家數、營收中位數、標準差或龍頭大廠集中度（如單一晶圓代工大廠佔比）【檔案觀察】。
  * **時間季節性資訊損失**：全年度聚合為單一靜態數值，且檔案內未附帶「年度／期別」欄位，無法單靠此檔觀察各雙月／季度或歷年之景氣波動【檔案觀察】。
  * **四捨五入尾差**：因數值縮放至「億元」並取小數點後兩位，橫向與縱向加總存在 $\pm 0.01$ 億元（約新臺幣 100 萬元）之四捨五入尾差【檔案觀察】。
* **外推邊界警告 (Extrapolation Boundaries)**：
  1. **【合計列重複計算風險 (Double Counting)】 → 絕對不能將全檔 `19` 列直接加總或取平均來推論全國科學園區規模**：因為第 7、13、18 列為三大園區之「合計」列，第 19 列為全區「總計」列。若分析時未先剔除這 4 列彙整列，任何總和（Sum）、平均值（Mean）或佔比（Share）分析都會發生嚴重的重複計算（總營業額會被算成 `174,030.69` 億元，恰為真實總計 `58,010.23` 億元的 3 倍）【檔案觀察】。
  2. **【生態謬誤 (Ecological Fallacy)】 → 不能從「子園區總營業額極高」推論「該園區內所有個別企業營收皆高或獲利能力皆強」**：例如臺南園區積體電路營業額高達 `25,759.91` 億元（佔全國科學園區總營收 `44.41%`）【檔案觀察】，但高度聚合數據可能由極少數超大型先進製程晶圓代工廠貢獻絕大多數營收，不能直接外推為該子園區內中小型廠商之平均營收表現，亦不能將「營業額（銷售淨額減可抵減項目）」直接等同於「附加價值（Value Added）」或「稅後淨利（Net Profit）」。
  3. **【母體涵蓋偏差】 → 不能將本表各產業佔比直接外推為「全臺灣整體科技產業結構」**：例如本表中積體電路產業佔科學園區總營業額高達 `83.25%`（`48,292.63 / 58,010.23`），電腦及周邊產業僅佔 `3.30%`（`1,917.20 / 58,010.23`）【檔案觀察】；這是因為晶圓製造高度集中於科學園區，而許多大型電腦品牌與伺服器系統組裝廠設址於科學園區外（如桃園、新北等地工業區）或採海外生產，故不可外推為全國總體產業產值比例。

## 7. 可執行 Python 防呆載入與分流程式（經實測驗證）

> **環境與依賴說明**：需安裝 `pandas`（Python 3.8+）。以下程式碼已針對實際檔案 `國家科學及技術委員會科學園區產業營業額統計表.csv` 實測執行驗證通過，確認無欄名撞名、無數值轉型失敗，且三層分流（15 筆明細 + 3 筆合計 + 1 筆總計 = 19 筆）完全互斥吻合。

```python
import csv
import pandas as pd

def load_nstc_science_park_revenue(csv_path: str):
    """
    載入並驗證《國家科學及技術委員會科學園區產業營業額統計表.csv》 (data.gov.tw/dataset/7597)
    保留原檔不改動，於記憶體副本執行欄名清理、安全數值轉型與三層彙整分流。
    """
    # 1. 嚴格位元組編碼檢測
    with open(csv_path, 'rb') as f:
        raw_bytes = f.read()
    has_bom = raw_bytes.startswith(b'\xef\xbb\xbf')
    
    decoded_text = None
    used_encoding = None
    for enc in ['utf-8-sig', 'utf-8', 'cp950', 'big5']:
        try:
            decoded_text = raw_bytes.decode(enc)
            used_encoding = enc
            break
        except UnicodeDecodeError:
            continue
            
    if decoded_text is None:
        raise ValueError(f"無法以候選編碼 (utf-8-sig, utf-8, cp950, big5) 解碼檔案：{csv_path}")
        
    # 2. 初始以純字串讀取，關閉預設 NA 解析以防吞掉特殊代碼
    df_raw = pd.read_csv(csv_path, encoding=used_encoding, dtype=str, keep_default_na=False)
    
    # 3. 清理欄名首尾空白與隱形字元，並防範撞名
    orig_cols = list(df_raw.columns)
    clean_cols = [c.replace('\ufeff', '').replace('\u200b', '').strip() for c in orig_cols]
    if len(set(clean_cols)) != len(clean_cols):
        raise ValueError(f"欄名清理後發生重複撞名：{clean_cols}")
    col_mapping = dict(zip(orig_cols, clean_cols))
    
    df = df_raw.copy()
    df.columns = clean_cols
    
    # 4. 針對已確認之數值欄位進行安全轉型（分開檢查原始空值與轉型失敗，絕不靜默轉 NaN）
    num_cols = [
        '積體電路產業營業額(億元)', '光電產業營業額(億元)', '電腦及周邊產業營業額(億元)',
        '通訊產業營業額(億元)', '精密機械產業營業額(億元)', '生物技術產業營業額(億元)',
        '其他產業營業額(億元)', '總計營業額(億元)'
    ]
    for col in num_cols:
        if col not in df.columns:
            raise KeyError(f"缺少預期數值欄位：{col}")
        s_clean = df[col].str.strip().str.replace(',', '', regex=False)
        empty_mask = (s_clean == '')
        if empty_mask.any():
            raise ValueError(f"欄位 [{col}] 發現 {empty_mask.sum()} 筆原始空值，中止轉型！")
        converted = pd.to_numeric(s_clean, errors='coerce')
        fail_mask = converted.isna()
        if fail_mask.any():
            bad_examples = df.loc[fail_mask, col].tolist()[:5]
            raise ValueError(f"欄位 [{col}] 發現 {fail_mask.sum()} 筆非數值內容（範例：{bad_examples}），中止轉型！")
        df[col] = converted.astype(float)
        
    # 5. 混合層級互斥分流：子園區明細列 (15筆)、園區合計列 (3筆)、全區總計列 (1筆)
    mask_grand_total = (df['園區別'] == '總計') & (df['子園區'] == '總計')
    mask_park_subtotal = (df['園區別'] != '總計') & (df['子園區'] == '合計')
    mask_subpark_detail = (df['園區別'] != '總計') & (df['子園區'] != '合計')
    
    df_detail = df[mask_subpark_detail].copy().reset_index(drop=True)
    df_subtotal = df[mask_park_subtotal].copy().reset_index(drop=True)
    df_grand_total = df[mask_grand_total].copy().reset_index(drop=True)
    
    # 嚴格驗證分流互斥且筆數總和精確等於原檔
    assert len(df_detail) + len(df_subtotal) + len(df_grand_total) == len(df), "分流筆數總和與原檔不一致！"
    assert not (mask_grand_total & mask_park_subtotal).any(), "總計列與小計列條件重疊！"
```

## 6. 已知限制與外推邊界 (Known Limitations & Caveats)
* **抽樣偏差與涵蓋盲區 (Sampling Bias & Coverage Gaps)**：
  * **僅含「公司法人」總公司登記於園區者，未涵蓋「分公司」或「外國公司在臺辦事處／非公司組織」**（除非曾辦理認許）：部分跨國科技企業或國內大型大廠於科學園區內設立的是「工廠」、「分廠」或「分公司」（例如總公司設於臺北市或新北市，但在竹科或南科設廠營運），若其「公司登記本籍地址」不在園區內，則是否被納入本「公司登記」資料集存在涵蓋盲區【推論待確認】。

  3. **【跨資料集串接與重名限制】 → 不能以 `公司名稱` 作為跨表 Join 的唯一鍵，且 `62` 筆非純數字統編無法串接財稅資料庫**：本檔有 `7` 組同名公司（新舊統編並存），以名稱 Join 會產生笛卡兒積（Many-to-Many）膨脹；此外，`'ZZZZ0002'`～`'ZZZZ0421'` 與 `'A03...'` 共 `62` 筆代編統編無法與財政部或國科會標準 8 碼數字統編資料表對應【檔案觀察】。

## 7. 可執行 Python 防呆載入、代碼串接與分流程式（經實測驗證）

> **環境與依賴說明**：需安裝 `pandas` 及支援讀取舊版 `.xls` 之引擎（如 `xlrd`）。以下程式碼已針對實際檔案 `3大科學園區公司資料集.csv` 與 `公司登記_公司狀態代碼對照表.xls` 實測執行驗證通過：自動處理 UTF-8 BOM、清理 `'備註 '` 尾部空白、保護統編與狀態代碼前置零、自動略過 `.xls` 前 3 列非表頭資訊完成 33 碼對照串接，並執行防呆分流驗證。

```python
import pandas as pd

def load_science_park_companies(csv_path: str, code_xls_path: str = None):
    """
    載入並驗證《3大科學園區公司資料集.csv》 (data.gov.tw/dataset/29277) 與附屬《公司登記_公司狀態代碼對照表.xls》
    保留原檔不改動，保護前置零，清理欄名尾部空白，串接狀態中文說明並執行分流。
    """
    # 1. 嚴格位元組編碼檢測
    with open(csv_path, 'rb') as f:
        raw_bytes = f.read()
    has_bom = raw_bytes.startswith(b'\xef\xbb\xbf')
    
    decoded_text = None
    used_encoding = None
    for enc in ['utf-8-sig', 'utf-8', 'cp950', 'big5']:
        try:
            decoded_text = raw_bytes.decode(enc)
            used_encoding = enc
            break
        except UnicodeDecodeError:
            continue
            
    if decoded_text is None:
        raise ValueError(f"無法以候選編碼 (utf-8-sig, utf-8, cp950, big5) 解碼檔案：{csv_path}")
        
    # 2. 全欄位強制以字串 (str) 讀取，保護「統一編號」與「公司狀態」之前置零不被吞掉
    df_raw = pd.read_csv(csv_path, encoding=used_encoding, dtype=str, keep_default_na=False)
    
    # 3. 清理欄名首尾空白與隱形字元（修正第 5 欄 '備註 ' 之尾部空白）
    orig_cols = list(df_raw.columns)
    clean_cols = [c.replace('\ufeff', '').replace('\u200b', '').strip() for c in orig_cols]
    if len(set(clean_cols)) != len(clean_cols):
        raise ValueError(f"欄名清理後發生重複撞名：{clean_cols}")
    col_mapping = dict(zip(orig_cols, clean_cols))
    
    df = df_raw.copy()
    df.columns = clean_cols
    
    # 4. 驗證主鍵與核心代碼欄位格式（本資料集無數值運算欄位，不強制將識別碼轉數值）
    if (df['統一編號'].str.strip() == '').any():
        raise ValueError("發現空白之『統一編號』紀錄！")
    if df['統一編號'].duplicated().any():
        dup_bans = df.loc[df['統一編號'].duplicated(), '統一編號'].tolist()[:5]
        raise ValueError(f"『統一編號』存在重複值（範例：{dup_bans}）！")
    if not df['公司狀態'].str.match(r'^\d{2}$').all():
        bad_status = df.loc[~df['公司狀態'].str.match(r'^\d{2}$'), '公司狀態'].unique().tolist()
        raise ValueError(f"『公司狀態』存在非 2 位數字格式之異常代碼：{bad_status}")
        
    # 5. 若提供《公司登記_公司狀態代碼對照表.xls》，自動定位第 4 列表頭並進行防呆串接
    if code_xls_path is not None:
        xls = pd.ExcelFile(code_xls_path)
        raw_xls = pd.read_excel(code_xls_path, sheet_name=xls.sheet_names[0], dtype=str, keep_default_na=False)
        
        # 尋找真實表頭列 ('Company_Status')，略過前 3 列標題與製表日期
        header_indices = raw_xls.index[raw_xls.iloc[:, 0].str.strip() == 'Company_Status'].tolist()
        if not header_indices:
            raise ValueError(f"無法在代碼對照表 {code_xls_path} 中定位 'Company_Status' 表頭列！")
        h_idx = header_indices[0]
        
        code_df = raw_xls.iloc[h_idx + 1:, :2].copy()
        code_df.columns = ['Company_Status', 'Company_Status_Desc']
        code_df['Company_Status'] = code_df['Company_Status'].str.strip()
        code_df['Company_Status_Desc'] = code_df['Company_Status_Desc'].str.strip()
        code_df = code_df[code_df['Company_Status'] != ''].reset_index(drop=True)
        
        if code_df['Company_Status'].duplicated().any():
            raise ValueError("代碼對照表中存在重複的 Company_Status 主鍵！")
            
        df = df.merge(code_df, left_on='公司狀態', right_on='Company_Status', how='left')
        unmapped_mask = df['Company_Status_Desc'].isna()
        if unmapped_mask.any():
            bad_codes = df.loc[unmapped_mask, '公司狀態'].unique().tolist()
            raise ValueError(f"主資料集發現無法對應至對照表之公司狀態代碼：{bad_codes}")
            
    # 6. 混合層級與業務狀態互斥分流
    # (a) 檢查是否混入合計/總計彙整列（本檔實測為 0 筆，保留可驗證之空分流）
    mask_summary = df['統一編號'].isin(['合計', '總計', '小計']) | df['公司名稱'].isin(['合計', '總計', '小計'])
    df_summary = df[mask_summary].copy().reset_index(drop=True)
    df_detail = df[~mask_summary].copy().reset_index(drop=True)
    assert len(df_summary) + len(df_detail) == len(df), "彙整列與明細列分流筆數總和與原檔不一致！"
    
    # (b) 將明細依營運狀態分流為「核准設立存續公司 ('01')」與「非正常存續/歷史消滅公司 (其他狀態)」
    mask_active = (df_detail['公司狀態'] == '01')
    df_active = df_detail[mask_active].copy().reset_index(drop=True)
    df_inactive = df_detail[~mask_active].copy().reset_index(drop=True)
    assert len(df_active) + len(df_inactive) == len(df_detail), "營運狀態分流筆數總和與明細筆數不一致！"
    
    print(f"[載入成功] 檔案：{csv_path} | 採用編碼：{used_encoding} (BOM={has_bom})")
    print(f"[欄名清理] 原始欄名對照：{col_mapping}")
    print(f"[分流核對] 原檔總列數={len(df)} | 彙整列(df_summary)={len(df_summary)} | 公司明細(df_detail)={len(df_detail)}")
    print(f"[狀態分流] 核准設立存續公司(df_active, 代碼 '01')={len(df_active)} 筆 | 解散/合併解散/撤銷/廢止等(df_inactive)={len(df_inactive)} 筆")
    return df_detail, df_active, df_inactive, df_summary

if __name__ == '__main__':
    CSV_FILE = '3大科學園區公司資料集.csv'
    XLS_FILE = '公司登記_公司狀態代碼對照表.xls'
    df_detail, df_active, df_inactive, df_summary = load_science_park_companies(CSV_FILE, XLS_FILE)
```
