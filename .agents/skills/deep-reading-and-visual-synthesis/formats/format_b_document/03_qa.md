# Format B 品質驗收與交付清單（Document & Medium QA Gate）

> **單一職責定位（Single Responsibility）**：本檔為 **Format B（文體 1～4 A4 PDF 深度報告 ／ 文體 5 Medium 專欄）** 建構完成後的雙軌驗收閘門，依本次選定體裁執行對應檢核（Subagent 隔離內部驗收完成後再回報主對話交付確認）。

## 一、 軌道 A：文體 1～4（A4 PDF 深度報告）品管驗收

### 1. 自動化轉圖與全頁實地檢視
```python
from verify_visual_outputs import render_pdf_to_pngs, cleanup_preview_artifacts

preview_pngs = render_pdf_to_pngs(output_pdf_path, dpi=180)
```
對 `preview_pngs` 產出的每一頁 `_preview_<stem>_pNN.png` 逐一呼叫 `read_file` 實地檢查以下 7 項硬指標：

1. **防溢位斷框檢查**：所有 `.card`、`.matrix-box`、`<figure>`、`.equation-box`、`.callout` 及模式 2 編輯室組件之**四邊框線 100% 完整閉合**，無卡片底部斷框或文字截斷。
2. **分頁與防斷頭孤尾**：無孤行標題（Orphan `h2`/`h3`/`h4` 單獨留在頁底）、無表題與表格分離、短表（`<= 5` 列）未被拆頁、長表（`> 5` 列）續頁頂端正確重複 `<thead>`、無無故半頁大塊空白帶。
3. **配圖適配與嚴格解耦**：無縮小硬塞之高密度 Format A 知識圖譜或 A4 橫向跨頁；內建 A4 直向簡圖（`7.44"`）文字清晰（`8.5–10.8pt`）且不爆版；Format D 統計圖搭配完整 `<figcaption>` 與前後正文互文導讀。
4. **字體與排版模式核對**：若選定 `clreq_kaiti`，確認全篇為標楷體且散文段落首行空兩格（`2em`），表格／卡片／收斂框／圖說不縮排；若選定 `modern_sans`，確認正黑體階層與行高呼吸感。
5. **筆風與去元語言穿透**：確認 `Slot 1 / 3 / 4 / 8` 語氣一致、零內部流程詞彙洩漏、高張力修辭無重複、事實與因果零捏造。
6. **特例跨格式連動檢查**：預設與 Format C 獨立（無自創 PPTX 頁次表）；唯有使用者明確要求列簡報頁次配當時，確認總頁數與頁次與最終 `.pptx` 100% 一致。
7. **清理暫存並交付**：驗證全數無瑕後立即呼叫 `cleanup_preview_artifacts(out_dir)` 清除所有 `_preview_*.png` 與 `_tmp_*.html`，再向使用者交付並於藍圖 `## Format B 分枝藍圖` 勾選 `- [x]`。

## 二、 軌道 B：文體 5（Medium 數據敘事專欄）品管驗收

1. **自動化分離計字與原生語法驗證**（CLI 或 Python API）：
   ```bash
   python .agents/skills/deep-reading-and-visual-synthesis/scripts/verify_visual_outputs.py --verify-medium "<02_medium_article.md>"
   ```
   - 確認 `---` 上方正文嚴格 `<= 1,600` 繁體中文字（含主副標題、引言塊、圖片替代文字）；
   - 確認**零自訂 HTML 標籤**（無 `<div>`/`<figure>`/`<table>`）、**零 Markdown 表格**、**免編譯 A4 PDF**。
2. **文末來源與雙軌統計檢核**：
   - `---` 下方僅列原始官方發布機關與資料集名稱，每筆僅附「1. 官方資料集網址、2. 資料涵蓋期間」；**嚴禁將「資料說明書」列為資料來源**；
   - 文稿最底端已印出 `📊 字數統計：正文共 XXX 字（不含文末參考資料來源...）`。
3. **配圖與課堂繳交區塊確認**：
   - 搭配之 1～2 張獨立單面板統計圖已完成 `read_file` 實地檢查（無 `ncols=2` 並排雙子圖）；
   - 回覆結尾附上一鍵複製課堂繳交區塊（指向 `01_phase1_socratic_log.md`，**絕不附掛 `02_phase2_generation_blueprint.md` 連結**），獲確認後於藍圖勾選 `- [x]`。
