# Format C 內容細節規劃（Step 1 定位、DISCAS 視距地板、單一議題章節與模式 3 Tier/DNA 決策大腦）

> **單一職責定位（Single Responsibility）**：本檔為 **Format C（16:9 視距自適應簡報 `.pptx`）** 分枝的內容細節決策大腦，對應五步內容優先流程之 **Step 1（定位與視距地板）＋ Step 2（本分枝風格／模式 3 `Tier 1～3` 與 Topic Art Direction DNA 拍板）**，**僅當主幹 [`../../shared/router.md`](../../shared/router.md) 確定勾選 Format C 時按需開啟**。
> - **核心邊界（不提前鎖死版型）**：本檔專責協助使用者拍板「北極星認知轉移」、「獨立閱覽／兩棲 vs. 現場口說定位」、「以觀看視距 $D/H$ 反推 DISCAS `min_font_pt` 字級地板」、「坑 2 寫作顆粒度分流」、「單一議題章節清單」與「模式 3 `Tier 1/2/3` 及 DNA 卡」；**具體版型代號嚴禁在此階段早鎖**，須待 **Step 3 文案審核凍結**後，才於 **Step 4A** 依文案內在邏輯自動配框架對齊。
> - **自給自足邊界**：若簡報內僅需簡單流程、機制或四象限圖，直接於 [`02_build.md`](./02_build.md) 採用原生向量版型（`F3-A`、`F3-B`、`F4-A`）或模式 3 `Tier 3` `render_svg_to_png_300dpi` 渲染 HTML+SVG 透明底層，無須為此額外勾選 Format A 或 Format D。

## 一、 Step 1 核心診斷：北極星主線、DISCAS 視距地板與坑 2 情境觸發原則

### 1. 北極星認知轉移與使用情境判定
- **🎯 全簡報北極星認知轉移（Macro Audience-State-Transfer）**：確立 `<進場前：聽眾對本議題的既有迷思或痛點> ➔ <離場後：聽眾帶走的唯一核心洞見與決策行動>`（此欄僅用於控制跨頁敘事邏輯與講稿轉場，**嚴禁將 AST 標語直接印入投影片畫面**）。
- **媒介使用情境判定**：釐清本份簡報屬於 **「獨立閱覽／留存預讀」**、**「報告閱讀兩棲」** 或 **「現場投影口說主導」**（若同專案已選定 **Format B 深度報告**，建議採雙軌分工：完整論證與附表留存於 Format B，Format C 聚焦高視距口說輔助）。

### 2. ANSI/AVIXA V202.01（DISCAS）繁中視距反推 `min_font_pt` 地板公式表
以 `16:9` 畫布高 `7.5"`（`540pt`）與繁體中文無襯線黑體實字高係數（約 `0.85× em`）推算不可跌破的最小正文字級硬底線：

$$\text{min\_font\_pt} = \max\left(12.0,\ \text{round}\left(3.18 \times \frac{D\text{（最遠觀眾視距，公尺）}}{H\text{（螢幕／幕布畫面高度，公尺）}}\right)\right)$$

| 使用者選擇的觀看情境（或自訂 $D, H$） | 視距比 $D/H$ | 自動反推 `min_font_pt`（硬底線） | 自適應風格與排版連動方向 |
| :--- | :---: | :---: | :--- |
| **① 筆電近看／線上螢幕／留存預讀** | $\le 3.5$ | **`12.0pt`**（建議基準 `13.0–13.5pt`） | 閱讀自足檔：精煉完整短句，無框細線與單層輕卡並用 |
| **② 小型會議室／研討室**（`4–6m`） | `~4.0–5.0` | **`14.0pt`**（建議基準 `15.0–16.0pt`） | 報告閱讀兩棲檔：微縮句長、輕量化框線，遠近皆清晰 |
| **③ 標準大學教室投影**（`8–10m`） | `~5.3–6.7` | **`16.0–18.0pt`**（建議基準 `18.0pt`） | 教室口報檔：高比例無框分欄、禁 4 欄窄排、必要時附尾段 `Appendix` |
| **④ 大階梯教室／演講廳／Pitch**（`12m+`） | `>= 7.0` | **`20.0pt+`**（建議基準 `20–24pt`） | 大場衝擊檔：大量啟用 `F1-C` 巨幅焦點宣言與 `F5-A` 全幅主圖 |
| **⑤ 自訂物理距離**（輸入 $D$ 與 $H$） | 依實算 | **`max(12.0, round(3.18 * D / H))`** | 依算得之 `min_font_pt` 自動歸入對應級距 |

- **核心提醒（地板 ≠ 起跳線）**：`min_font_pt` 僅是「絕不可跌破的物理下限」，並非字級起跳線；進入 Step 4 排版時，仍會先依視覺呼吸感在地板之上訂定單一全檔目標設計基準字級 **`target_body_pt >= min_font_pt`**，杜絕逐頁字級亂跳。

### 3. 坑 2 情境觸發原則（寫作顆粒度分流，絕不靠縮字硬塞）
- **第一優先永遠是「增加頁數＋去框優化排版」**：實證證明在 `<= 18.0pt` 區間，透過拆除雙層套盒、釋放容器內死白與自然增加頁數即可完整承載內容，**絕不為了塞進舊頁數而縮字至低於 `min_font_pt` 或盲目刪減批判分支**。
- **短語錨點化之情境觸發條件**：是否進一步將畫面文字精煉為「關鍵短語＋數據錨點（完整推論入 `Speaker_Notes` ＋ 尾段選配 `Appendix` 備查頁）」，**依使用情境決定**——僅在 **「現場口說需防演說抑制效應（Wecker 2012）」** 或 **「`min_font_pt >= 20.0pt` 以上大場達物理容量門檻」** 時觸發精簡短語；獨立閱覽／兩棲情境則保留精煉完整短句。

## 二、 單一議題章節清單規劃與「不提前鎖死版型」鐵律

1. **首尾定錨（`F1-A`）＋ 四幕劇單一議題清單 ＋ 選配 `Appendix`**：
   - 第 1 頁為封面總覽、主結尾為峰終定律收斂頁（皆屬 `F1-A` 首尾定錨）；若有高密度備查數據／方法論表，可於主結尾後掛載選配 `Appendix` 備查頁供 Q&A 檢索。
   - 中段依 **Act I（現狀與痛點）$\rightarrow$ Act II（核心矛盾與模型）$\rightarrow$ Act III（架構、反例與實證）$\rightarrow$ Act IV（落地行動路線）** 展開，**不用死板總字數限縮議題**，而是靠「**關卡 A：單頁嚴格只承載 1 個獨立子問題或 1 個核心認知轉折** ＋ **關卡 B：簡報兩層組塊（Zone 2 主容器 `2～4` 個 × 每容器 `2～3` 點，全頁 `<= 6～8` 點）與 `min_font_pt` 物理底線**」防塞；容量吃緊時一律動態加頁，100% 無損承載 Phase 1 Step 5 全部分支。
   - **Zone 3 底部橫幅一律採按需選配（Optional）**：僅於需要跨欄綜合定律或外推紅線時選配，不強制每頁繪製。
2. **本階段嚴禁提前鎖死版型代號（Defer Layout Lock to Step 4A）**：
   - 文案尚未定稿前硬猜版型極易逼出套框填字味。本階段僅確認各頁單一議題、認知轉折與預計掛載之 Format D 圖表（若圖表需針對高視距另存無重標 `*_slide.png`，於此備註連動，細則見 [`../format_d_charts/02_build_core.md`](../format_d_charts/02_build_core.md)）。
   - 下方僅供了解後續 Step 4A 兩段式語義自動配框架可調度的 **五大簡報版型家族（13 精煉版型：1 首尾定錨 ＋ 12 內容與衝擊版型）**（完整幾何、配比與新舊代號映射見 [`02_build.md`](./02_build.md)）：
     - **家族 1｜破題與節奏**：`F1-A`（封面／封底，原 `S0`，首尾定錨）、`F1-B`（極簡章節過場頁，原 `S13`）、`F1-C`（巨幅焦點宣言頁，合原 `Hero Stat`＋`S14`）
     - **家族 2｜觀點並陳與結構展開**：`F2-A`（並列／對比欄，合原 `S1`＋`S2`）、`F2-B`（瑞士網格「左標右展」橫列，原 `S8`）、`F2-C`（不對稱便當盒網格 Bento，原 `S9`）
     - **家族 3｜時序、因果與機制**：`F3-A`（流程軌道／上下交錯時間軸，合原 `S3`＋`S12`）、`F3-B`（精簡機制架構圖，原 `S4`，限 3～5 節點）
     - **家族 4｜多維比較與分類**：`F4-A`（2×2 正交四象限，原 `S5`）、`F4-B`（極簡三線比較表，原 `S11`，含 `Appendix` 備查）
     - **家族 5｜數據實證與公式解剖**：`F5-A`（主圖＋四向無框導讀，原 `S7`／`S7-A/B/C/D`）、`F5-B`（頂部指標橫帶＋下方洞察，原 `S10`）、`F5-C`（焦點公式／指標解剖，原 `S6`）

## 三、 本分枝混合式局部覆寫 ＆ Format C 模式 3（`bespoke_metaphor`）專屬機制

確認 Format C 是否承襲主幹 [`../../shared/style_and_color_core.md`](../../shared/style_and_color_core.md) 之模式／筆風／色票，或於本分枝局部覆寫（筆風 `Slot 1 / 7 / 8`、靜態佈景或動態主題色票 `derive_slide_theme_from_topic()`）。

### Format C 開啟模式 3 專屬機制：主動推薦 `Tier`、差異揭露與 Topic Art Direction DNA 卡
當 Format C 評估或開啟模式 3（`bespoke_metaphor`）時，**AI 嚴禁預設硬套單一等級**，必須先依本次「主題屬性」與「簡報用途」向使用者進行以下三項揭露，再由使用者最終拍板等級：
1. **主動給出推薦等級與理由**（例如建議 `Tier 1` 或 `Tier 2`）；
2. **具體描述 `Tier 1 / Tier 2 / Tier 3` 在本主題下的實際視覺隱喻與設計長相**；
3. **透明比較三等級在 PowerPoint 改字彈性與生成成本上的差異**：

| 模式 3 等級 | 技術構成與視覺表現 | PowerPoint 後續改字彈性 | 生成成本與依賴 |
| :---: | :--- | :--- | :--- |
| **`Tier 1`** | **100% 原生幾何原語**（斜切色面、刻度尺線、階段台階、向量天平、巨型序號）＋ **`derive_slide_theme_from_topic()` 動態主題色票** | **最高（全頁 100% 原生可改字與調幾何）** | 最低（純 `python-pptx` 原生向量） |
| **`Tier 2`** | `Tier 1` ＋ 封面／過場／至多 1 頁破題頁加入 **呼叫 `image-generator` 子代理生成之無文字概念主視覺**（存於 `02_outputs/assets/`，預留乾淨負空間，中文原生標題疊加其上；中段 70%～80% 頁維持全原生） | **高（全文字 100% 原生可改；僅概念底圖重繪需重跑生圖）** | 中（增 1～3 張無字概念圖） |
| **`Tier 3`** | `Tier 1/2` ＋ **1～2 頁最核心機制頁 HTML+SVG `300 DPI` 透明底層嵌入**（平滑貝茲濾網漏斗、失衡天平、冰山分層；**頁頂標題與旁側導讀維持 PowerPoint 原生可編輯**） | **中高（標題與導讀皆原生可改；該 1～2 頁 SVG 視覺底層須改 HTML/SVG 重渲）** | 較高（調用 `render_svg_to_png_300dpi`，Playwright+Chromium 優先、退回 Chrome/Edge CLI） |

- **三大創意元素與主題目標強對齊規範**：
  1. **動態主題色票（`derive_slide_theme_from_topic()`）**：依主題語義與場域（開燈教室淺底安全組優先 vs. 可控深場發表）於 CIELAB 推導色票並強制通過 WCAG AA（$\ge 4.5:1$），杜絕千篇一律商務藍；
  2. **`image-generator` 無文字概念主視覺（存於 `02_outputs/assets/`）**：緊扣唯一核心隱喻且預留乾淨負空間，嚴禁商務握手／發光大腦圖庫照與無關裝飾圖（Bartsch & Cobern 2003）；
  3. **HTML+SVG `300 DPI` 透明視覺底層**：僅服務 1～2 頁核心系統／因果隱喻，視覺語彙與色票須與原生頁一體成型，標題與註解維持原生可編輯。
- **Topic Art Direction DNA 卡（使用者拍板後寫入 `02_phase2_generation_blueprint.md` 之 `## Format C 分枝藍圖`）**：
  ```markdown
  - **Topic Art Direction DNA 卡（Format C 模式 3）**：
    - **拍板等級與理由**：`Tier 1` / `Tier 2` / `Tier 3` — <選型依據>
    - **唯一核心視覺母題（限 1 個）**：<例：訊號雜訊濾網 / 階梯天平 / 深度切面>
    - **動態主題色票性格**：<主題語義鍵或代表 HEX ➔ `derive_slide_theme_from_topic(mode="light_classroom"|"dark_stage")`>
    - **創意頁面配額（嚴守 `20/80` 克制紅線）**：<明確列出哪 1～3 頁使用概念圖／SVG 底層，其餘 70%～80% 頁採乾淨無框細線承托>
  ```

## 四、 分枝提案格式與下游雙強制停頓關卡預告

向使用者提出 **Format C 分枝提案** 時，須完整列出：
1. **🎯 北極星認知轉移（Macro AST）**：`<進場前迷思/痛點> ➔ <離場後核心洞見/行動>`
2. **📏 觀看情境、DISCAS `min_font_pt` 地板與坑 2 寫作顆粒度定位**：列明所選情境（或 $D, H$）、算得之 `min_font_pt` 硬底線，以及採「精煉完整短句」或「關鍵短語錨點＋講稿主導」。
3. **🎨 分枝風格覆寫／模式 3 `Tier` 與 DNA 卡提案**（若開啟模式 3 須含上述三項揭露）。
4. **🗂️ 單一議題章節清單草案（本階段刻意不鎖版型代號）**：

| 序號 | 幕次／單一議題 | 聽眾認知轉折（AST: Before ➔ After） | 核心論點與斷言方向（草案） | 視覺證據／Format D 圖表連動備註 |
| :---: | :---: | :--- | :--- | :--- |
| `1` | 封面 | 建立問題張力與期待錨點 | ... | 首頁定錨（`F1-A`） |
| `2...` | Act I～IV（每頁限單一子議題） | `<前頁懸念/盲點> ➔ <本頁破局認知>` | ... | `<是否掛載某 Format D 圖表／需否 *_slide.png／公式或機制說明>` |
| `N` | 封底（＋選配 Appendix） | 收斂行動呼籲與決策錨點 | ... | 峰終結尾（`F1-A`；若需備查附表則加掛 Appendix） |

5. **下游雙強制停頓關卡與 Subagent 邊界預告（詳見 [`02_build.md`](./02_build.md) 與 [`03_qa.md`](./03_qa.md)）**：
   - **Step 3 ⏸️ 文案審核關卡 ＆ 拍板文案保真鐵律（Approved Copy Fidelity Rule）**：主對話以人眼好讀之 Markdown 逐頁呈現文案草案供使用者審核拍板（不讓使用者讀原始 JSON），拍板後凍結寫入工作階段根目錄之 `02c_slide_spec_lock.json`（`copy` 區）；文案一經凍結即嚴禁 Step 4 未經同意壓縮或刪改內容（極端孤兒字微調須先列修改前後對照徵求同意）。
   - **Step 4A ⏸️ 渲染前純文字配置對齊關卡**：文案凍結後、動手渲染 `.pptx` 前，以人眼好讀之純文字「逐頁版面配置＋配圖對齊表」經使用者點頭鎖入 `02c_slide_spec_lock.json`（`layout` 區）；隨後可將 **Step 4B（確定性渲染）＋ Step 5（[`03_qa.md`](./03_qa.md) 方案 C 三階內部品管）** 交由獨立 Subagent 或單執行緒執行完畢後交付。

**⏸️ 暫停關卡**：等待使用者確認 Format C 定位、DISCAS `min_font_pt` 地板、單一議題章節清單與分枝覆寫（含模式 3 Tier/DNA）後，立即寫入 `02_phase2_generation_blueprint.md` 之 **`## Format C 分枝藍圖`**，輪到 Format C 執行時進入 [`02_build.md`](./02_build.md)！
