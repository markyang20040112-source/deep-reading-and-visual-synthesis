# Format C 品質驗收與方案 C 三階內部品管（Slide QA Gate）

> **單一職責定位（Single Responsibility）**：本檔為 **Format C（16:9 視距自適應簡報 `.pptx`）** Step 5 的強制品管流程，執行 **`default_slide_qa_mode = "option_c_2x2_and_high_risk"`（方案 C 三階分級視覺品管）**。
> - **角色定位**：三階視覺品管與診斷拼圖**僅供 AI（或隔離 Subagent）在交稿前執行內部自我品質把關**，不丟給使用者逐頁盯圖；唯遇「單字孤兒換行調幾何仍無解而須微調文案」等例外時，始列出修改前後對照徵求使用者同意。

---

## 一、 方案 C QA 黑盒 API 簽名（`scripts/verify_visual_outputs.py`）

```python
# === scripts/verify_visual_outputs.py (Option C 3-Tier Internal QA Engine) ===
from verify_visual_outputs import (
    verify_pptx_structure,          # (pptx_path, min_font_pt=None, profile="reading", spec_lock_path=None, ...) -> Dict (passed, errors, warnings, high_risk_slides)
    render_pptx_to_pngs,            # (pptx_path, out_dir=None, width_px=1920, height_px=1080, dpi=None, slide_indices=None) -> List[str] (3-strategy full or single-slide re-render)
    build_pptx_contact_sheet,       # (png_paths, out_path, cols=4, rows=4, ...) -> str (4x4 deck rhythm overview)
    build_pptx_qa_grids,            # (png_paths, out_dir, ...) -> List[str] (1920x1080 HD 2x2 four-up QA grids, 960x540 per tile)
    cleanup_preview_artifacts,      # (target_dir) -> List[str] (Removes _preview_*.png, slide_*.png, _qa_contact_*.png, _qa_grid_*.png)
)
```

## 二、 方案 C 三階分級視覺品管流程（3-Tier Internal QA Protocol）

### 第一階：0 視覺 Token 程式全掃（`verify_pptx_structure`）
執行 `verify_pptx_structure(pptx_path, min_font_pt=..., spec_lock_path=".../02c_slide_spec_lock.json")`（全面以 Pillow 真實字寬 `measure_text_layout()` 把關）：
- **Hard Error（`passed: False`，強制修復）**：
  - 內容字級低於 `min_font_pt`
  - 物理穿框或超出動態畫布邊界
  - **任意兩非背景內容框邊界碰撞**
  - **`Zone 2 / Zone 3` 重疊碰撞**
  - 缺 `Speaker_Notes` 講稿
  - 畫面殘留未替換之 `**` / `TBD` / `TODO`
  - 與 `02c_slide_spec_lock.json` 文案或關鍵數字（百分比／金額／年份）保真失配
- **Soft Warning（幾何優化提醒）**：
  - 單字孤兒換行（尾行 `<= 2` 漢字＋標點）
  - 嵌入圖縮放比 `< 0.80×` 或實效 PPI `< 150`（須從同腳本另存 1:1 `*_slide.png`）
  - 局部過滿或過空、左右視覺失衡
  - **上下垂直頭重腳輕（Vertical Top-Heavy：中段內容頁若 `Zone 2 上方留白 < 0.30"` 且 `底部空白 > 1.80"` 即提醒，排除 `F1-A/F1-B` 首尾過場頁與已有合理置中留白之頁面）**
  - 方塊卡片頁佔比 `> 40%`、單一家族佔比 `> 40%`、雙層套盒、圖旁疊卡
- **自動輸出 `high_risk_slides` 清單**：涵蓋 `F5-A` 圖表頁、`F4-B` 表格頁、`F5-C` 公式頁、模式 3 視覺頁、任何 Warning 頁與填滿率 `> 75%` 頁。

### 第二階：100% 全頁低費率視覺掃描（`4×4` 接觸表 ＋ `2×2` 高清四宮格）
1. 調用 `render_pptx_to_pngs(pptx_path, out_dir=out_dir)` 轉出 `1920×1080` 頁面圖。
2. 輸出並以 `read_file` 檢視 **1 張 `4×4` 全覽接觸表**（`build_pptx_contact_sheet()` 鳥瞰全檔節奏、配色與去方塊比例）。
3. 依序以 `read_file` 檢視全部 **`1920×1080` 高清 `2×2` 四宮格**（`build_pptx_qa_grids()`，每格 `960×540`，`12pt` 繁中清晰可辨，達成 **100% 全頁視覺覆蓋**）。

### 第三階：高風險頁滿版精檢 ＋ `slide_indices` 單頁局部重繪覆檢
1. 僅針對 `high_risk_slides` 清單呼叫 `read_file` 檢視單張 `1920×1080` 滿版大圖細檢。
2. 若發現局部瑕疵：
   - **幾何優先原則**：先調框高、欄寬、換版型或拆頁，**絕不未經授權縮字低於 `target_body_pt` 或 `min_font_pt`**；唯幾何無解須微調文案時，先列修改前後對照徵求使用者同意並同步更新 `02c_slide_spec_lock.json`。
   - **單頁局部重繪覆檢**：調用 `render_pptx_to_pngs(..., slide_indices=[k])` 僅重繪該頁（若改動版型或頁序則連同前後鄰頁）並以 `read_file` 覆檢。

---

## 三、 清理與交付關卡

1. 確認全頁無 Hard Error 且視覺無瑕後，立即執行 `cleanup_preview_artifacts(out_dir)`（或 CLI `verify_visual_outputs.py --cleanup`）清空所有 `_preview_*.png`、`slide_*.png`、`_qa_contact_*.png` 與 `_qa_grid_*.png`。
2. 確認僅交付正式 `.pptx`、正式腳本與根目錄 `02c_slide_spec_lock.json`；向使用者交付並獲確認後，於 `02_phase2_generation_blueprint.md` 之 `## Format C 分枝藍圖` 勾選 `- [x]`。
