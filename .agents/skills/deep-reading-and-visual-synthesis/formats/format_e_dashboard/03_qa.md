# Format E 封裝結構、色彩鎖定與視覺品管驗收清單（Dashboard QA Gate）

> **單一職責定位（Single Responsibility）**：本檔為 **Format E（互動式 Web 數據儀表板 ＋ 選配靜態全景圖 `.png`）** 建構完成後的強制品管驗收閘門，於 [`02_build.md`](./02_build.md) 產出後、執行雲端直推部署前進行。

---

## 一、 第一階：自動化封裝與色彩鎖定驗證（CLI / Python API）

1. **Web 儀表板封裝體檢（`verify_dashboard_bundle`）**：
   ```bash
   python .agents/skills/deep-reading-and-visual-synthesis/scripts/verify_visual_outputs.py --verify-dashboard "<儀表板目錄>"
   ```
   強制確認全部通過：
   - 基礎檔案齊備：`index.html`、`css/style.css`、`js/gephi_palette.js`、`js/dashboard.js`、`data/*_data.js` ＋ `data/*_data.json` 雙載入檔、`.nojekyll`、`.gitignore`、`README.md`；
   - **零執行期 Tailwind CDN**（無 `cdn.tailwindcss.com`）；
   - **純 `./` 相對路徑**（無 `/` 開頭根目錄絕對路徑，確保 `file://`、Netlify/Cloudflare 根網域與 GitHub Pages 子路徑皆零 404）；
   - `css/style.css` 含 `:root` 集中變數與 `tabular-nums` 等寬數字設定；
   - `.gitignore` 已排除 `.netlify/`、`.wrangler/`，且目錄內**絕無殘留嵌套 `.git/`**（嚴禁子目錄 `git init`）。
2. **跨圖類別色彩登記表同步檢驗（`verify_color_registry`）**：
   ```bash
   python .agents/skills/deep-reading-and-visual-synthesis/scripts/verify_visual_outputs.py --verify-colors "<session_dir>"
   ```
   確認工作階段 `02_color_registry.json` 與 `js/gephi_palette.js` 內嵌之 `entityColors` / `entityAliases` 100% 一致，切換篩選／排序／頁籤時同名類別絕不換色。

---

## 二、 第二階：互動功能與靜態全景圖實地驗收

1. **互動邏輯與匯出核對**：
   - 確認所有維度篩選控制項、視角頁籤切換、自訂 `tooltip` 單位與佔比顯示、以及明細表搜尋／排序／CSV 匯出（含 `\uFEFF` UTF-8 BOM 防 Excel 中文亂碼）運作正常；
   - 確認零 Alpha 透明度冒充明度或徽章底色、`df_detail` 正規化未混入 `df_subtotal`、`df_other` 依拍板選項正確消歧、頁尾來源僅列原始官方發布機關與資料集（禁列「資料說明書」）。
2. **靜態全景儀表板圖（若採模式 C，含 `.png`）**：
   - 執行 `check_matplotlib_text_collisions(fig)` 零文字碰撞預檢，並以 `read_file` 實地檢查 `24" × 14"`, `300 DPI` 全景圖無文字重疊、無穿線、無溢界、零 Emoji 且圖例標題對齊。
3. **清理暫存、雲端部署紀錄與藍圖勾稽**：
   - 呼叫 `cleanup_preview_artifacts(out_dir)` 清除任何臨時測試腳本或廢棄預覽檔；
   - 若執行雲端直推部署（見 [`02_build.md`](./02_build.md) 第 4.2 節），確認已完成單一平台擇一部署、執行公開資料曝光提醒，並將 `provider`、站點／專案名稱、正式網址與部署日期寫回 `02_phase2_generation_blueprint.md` 之 **`## Format E 分枝藍圖`**；交付確認後勾選 `- [x]`。
