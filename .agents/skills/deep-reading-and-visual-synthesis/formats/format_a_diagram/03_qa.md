# Format A 視覺品管與交付驗收清單（Diagram QA Gate）

> **單一職責定位（Single Responsibility）**：本檔為 **Format A（視覺化知識圖譜 `.png`）** 建構完成後的強制品管驗收閘門，於 [`02_build.md`](./02_build.md) 產出圖檔後執行（Subagent 隔離內部自我驗收完成後再回報主對話交付確認）。

---

## 一、 第一階：0 視覺 Token 程式自動碰撞預檢

在儲存並開啟肉眼檢視前，於生成腳本中對每張 `fig` 強制呼叫 [`../../scripts/verify_visual_outputs.py`](../../scripts/verify_visual_outputs.py)：

```python
from verify_visual_outputs import check_matplotlib_text_collisions, cleanup_preview_artifacts

report = check_matplotlib_text_collisions(fig, shrink_pt=1.5, print_report=True)
assert report["passed"], f"Format A 文字碰撞或越界：{report}"
```

- 攔截任何**文字重疊**與**超出畫布邊界**之幾何錯誤；若未通過，立即調整卡片寬度、走廊寬度（`>= 6.2–7.4` X-units）或畫布高度（`12.6"–15.4"`）重跑，**嚴禁靠縮小字級至低於 `16.0pt`（內文）或 `13.4pt`（膠囊）硬塞**。

## 二、 第二階：實地影像檢視（`read_file` 逐張驗收）

對每張輸出至 `02_outputs/<nn>_*.png` 之正式圖檔呼叫 `read_file` 逐一實地目視核對以下 7 項硬指標：

1. **零穿線與真弧頂置中**：所有連線起訖點皆精準落於卡片邊緣（經 `box_edge_point(..., pad=0.20)` 補償），無任何連線穿過文字或卡片本體；弧形貝茲箭頭之謂詞膠囊精確置中於弧頂且不壓線。
2. **拓撲走廊與 Z-Order 分層**：`13.4~14.0pt` 謂詞膠囊與卡片徽章清晰可讀，與卡片框線留有寬裕呼吸距；卡片與文字居於連線之上（`zorder` 正確）。
3. **無損分圖與 $4 \to 2 \to 3$ 密度**：確認 Phase 1 收斂之核心論證與批判延伸分支無任何刪減；每張圖維持 3～4 個 Macro Zone、整體留白 $\ge 25\%$、卡片內無大塊空白拉伸。
4. **字型安全與避頭尾**：零彩色 Emoji、零 `□` 缺字方框、行首無違規標點（Kinsoku Shori）、行末無孤立開括號。
5. **筆風與去元語言穿透**：確認 `Slot 1 / 4 / 5 / 8` 語氣一致、零「Phase 1 / 蘇格拉底 / Step 1～5」等內部流程詞彙洩漏、事實與因果零捏造。
6. **色彩與設計模式一致**：符合 `## 0` 或 `## Format A 分枝藍圖` 指定之主題色票與模式 1/2/3 設定（模式 2 確認 80/20 聚光燈與瓶頸膠囊；模式 3 確認空間隱喻比例與可讀性）。
7. **清理暫存與交接**：呼叫 `cleanup_preview_artifacts(out_dir)` 清除任何臨時預覽或測試圖檔，僅保留正式 `.png` 與正式生成腳本 `.py`；交付使用者確認後於 `02_phase2_generation_blueprint.md` 的 `## Format A 分枝藍圖` 勾選 `- [x]`。
