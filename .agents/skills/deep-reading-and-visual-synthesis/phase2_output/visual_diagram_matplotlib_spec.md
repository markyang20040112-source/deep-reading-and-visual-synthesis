# 視覺化知識圖譜與概念架構圖規範（Format A: Visual Knowledge Diagram Spec）

> **單一職責定位（Single Responsibility）**：本檔專責 **Format A（視覺化知識圖譜 `.png`）** 的多圖拆分策略、五大瑞士網格拓撲（T1～T5）、主幹分叉連線與 `matplotlib`（搭配 [`generate_mindmap.py`](../scripts/generate_mindmap.py) 引擎）座標級渲染工程守則。跨格式共用的組塊階層、白話由淺入深原則與基礎色票請見 [`visual_cognition_principles.md`](visual_cognition_principles.md)。

> [!CAUTION]
> **核心鐵律**：嚴禁使用擴散生圖模型（Imagen / DALL-E）繪製中文字圖表！所有繁體中文知識圖譜必須 100% 由 Python `matplotlib` 精確渲染。

---

## 一、 認知負荷自動分圖與「首張全景主圖」鐵律

- **理論依據**：**前導組織體與宏觀結構理論（Ausubel 1968）** 與 **分段原則（Segmenting Principle, Sweller 2019）**。
- **分圖規範**：
  1. **禁止將全篇架構與深層機制硬塞入單張圖譜**：當知識同時涵蓋「原文完整脈絡」與「深層機制／雙腦架構拆解」時，必須拆分為 2～3 張獨立高解析度圖譜。
  2. **編號 `01` 強制為「本篇文章整體內容架構主圖（Article Master Structure Map）」**：100% 聚焦於原文從「背景痛點 $\rightarrow$ 核心診斷 $\rightarrow$ 關鍵機會/支柱 $\rightarrow$ 治理與結論」的完整脈絡，先為讀者建立單篇全域心智地圖。
  3. **編號 `02` 以後為「核心機制／雙軌架構深挖圖」**：針對文中最高價值的單一工程機制或決策框架進行 3×3 矩陣或雙軌匯流解剖。

## 二、 五大動態拓撲版型與主幹分叉路由（5 Topologies & Hierarchical Trunk-Fork）

繪圖前必須根據知識結構，從以下 5 種 `0～100` 瑞士網格拓撲中挑選最匹配的一種，並落實 [`visual_cognition_principles.md`](visual_cognition_principles.md) 的 **$4 \to 2 \to 3$ 階層組塊** 與 **由淺入深（淺層現象 $\rightarrow$ 中層情境 $\rightarrow$ 深層價值）白話敘事**：

| 拓撲代號與名稱 | 適用知識結構 | `0～100` 瑞士網格空間配置與連線規範 |
| :--- | :--- | :--- |
| **T1：焦點問題層級概念圖**<br>*(Top-Down Concept Map)* | 理論推導、學術論文、第一性原理拆解 | • **頂層（`Y: 76~86`）**：置中「焦點問題與核心定理樞紐」。<br>• **中層（`Y: 44~68`）**：並排 3～4 張「核心機制卡」，由頂層以帶謂詞膠囊之有向箭頭向下連接。<br>• **底層（`Y: 14~38`）**：對應之「實證與處方卡」，並以水平虛線標示跨分支連結。 |
| **T2：三欄雙腦／演進管線圖**<br>*(3-Column Pipeline / 3×3 Wiring)* | 雙腦協同架構、方法論步驟、痛點至處方鏈條 | • **水平 3 個垂直欄位（Columns）**：由左至右各外包一個 **Palmer 共同區域底色框（Macro Zone）**，每欄內含 3 張垂直堆疊子卡。<br>• **完整 3×3 拓撲連線**：第 1、2、3 層皆須具備完整的橫向與縱向有向關係膠囊連線，清楚呈現跨層協同機制。 |
| **T3：系統動力學雙迴路圖**<br>*(System Dynamics Loop)* | 商業生態、增強／調節反饋循環、跨篇統整 | • **中央迴路區（`X: 34~66`）**：配置兩個核心實體，以弧形有向箭頭連接並標註 `+ 增強 / - 調節` 謂詞膠囊。<br>• **兩側模組區（左 `X: 4~30`，右 `X: 70~96`）**：左右各配置共同區域容器連入中央。 |
| **T4：對照矩陣與雙欄架構**<br>*(Comparative / 2×2 Matrix)* | 典範轉移（舊 vs. 新）、人機分工、2×2 象限策略 | • **左右雙大區（左 `X: 4~48` vs. 右 `X: 52~96`）** 或 **中央十字四象限**。<br>• 左區採用 `danger` 警示色條，右區採用 `primary`/`success` 破局色條；中央以雙向對照膠囊橋樑逐層比較。 |
| **T5：瑞士網格全高主軸分叉圖**<br>*(Swiss Full-Spine & 4-Trunk Fork)* | 全篇全景結構總覽（現象、病因、解法、行動） | • **中央核心主軸（`X: 37~63, Y: 14.5~86.5`，`H=72.0` 全高無上下空洞）**：內嵌與 4 大分區一一對應的 **4 個核心步驟模組**。<br>• **4 主幹 $1 \to 2$ 分叉連線（`draw_hierarchical_trunk_fork`）**：嚴禁從中央直接拉出 8 條散亂細線；必須從中央 4 模組拉出 **4 條主幹**（於大區入口配置主幹關係膠囊），再**一分為二（$1 \to 2$ Fork）**連向區內的 2 張子卡片。<br>• **底部全寬收斂橫幅（`X: 3.5~96.5, Y: 2.0~10.2`）**。 |

## 三、 程式級渲染、畫布字級比例與垂直槽位真置中守則（Engine Rules）

直接匯入 [`scripts/generate_mindmap.py`](../scripts/generate_mindmap.py) 內建函數執行，嚴禁在個別腳本中重複複製繪圖底層邏輯：

1. **畫布與大字級雙行滿版配適**：
   - 畫布固定為 `figsize=(28, 18.5)`、`dpi=240`（僅輸出單一高畫質無損 `.png`）。
   - **字級硬指標**：卡片內文 **`11.8pt ~ 12.5pt`**、卡片標題 `14.6pt ~ 15.0pt`、分類徽章 `10.6pt`、分區大標題 `13.6pt`、底部橫幅標題 `14.4pt`／內文 `12.4pt`。
   - **雙行飽滿敘事（60～66 漢字／列點）**：每行約容納 34～36 個漢字；每條列點應撰寫 **60～66 字的完整白話敘事**，使其自然折為勻稱的 **2 滿行**，填滿卡片橫向寬度的 **`88%～92%`**。
2. **字型安全與全形縮排避頭尾保護**：
   - 繪圖前自動透過 `sanitize_cjk_glyphs()` 將微軟正黑體缺字（`➔`, `↔`, `⇄`）替換為安全字元（`→`, `×`），杜絕缺字方框（Tofu box）。
   - 折行時透過 `apply_kinsoku_shori()` 先剝離續行前導全形縮排（`\u3000 `），執行避頭尾標點交換後再掛回縮排，100% 杜絕行首逗號或行尾孤立左括號。
3. **Tufte 四層 Z-Order 深度分離與走廊膠囊定位**：
   - `zorder = 1`：`draw_macro_zone()` 繪製 Palmer 共同區域極淺底色容器框。
   - `zorder = 2`：`draw_hierarchical_trunk_fork()` 或 `draw_labeled_bezier()` 繪製平滑連線。
   - `zorder = 3~4`：`draw_modern_card()` 繪製微陰影、純白卡面、左側強調色條、標題膠囊與內文。
   - `zorder = 5`：關係謂詞膠囊**必須精確落於兩張卡片之間的空白走廊中央，嚴禁壓在卡片邊框線上**。
4. **卡片內「水平平行列槽幾何真置中（True Vertical Slot Centering）」**：
   - `draw_modern_card()` 將卡片可用垂直高度 `avail_h` 均分為 $N$ 個列槽，計算每個列槽的**幾何垂直中心 `slot_center_y = slot_top - slot_h / 2.0`**，將該列點的多行文字區塊整體垂直置中（`va="center"`），達成上下留白完全相等的平衡感。
