# 特化格式 A：視覺化知識圖譜與概念架構圖規範 (Visual Knowledge Diagram Spec)

> [!CAUTION]
> **核心鐵律**：嚴禁使用擴散生圖模型（Imagen/DALL-E）繪製中文字圖表！所有繁體中文知識圖譜必須 100% 由 Python `matplotlib`（搭配 [generate_mindmap.py](../scripts/generate_mindmap.py) 引擎）精確渲染。

## 一、 五大動態拓撲版型選型矩陣 `[依據：Eppler 2006; Novak 2008; Tversky 2011]`

繪圖前必須先根據文章知識結構，從以下 5 種拓撲版型中挑選最匹配的一種（嚴禁將所有文章都畫成單一放射狀心智圖）：

| 拓撲代號與名稱 | 適用知識結構 | 0～100 瑞士網格空間配置規範 |
| :--- | :--- | :--- |
| **T1：焦點問題層級概念圖**<br>*(Top-Down Concept Map)* | 理論推導、學術論文、第一性原理拆解 | • **頂層（Y: 76~86）**：置中「焦點問題與核心定理樞紐」。<br>• **中層（Y: 44~68）**：並排 3～4 張「核心機制卡」，由頂層以帶謂詞膠囊之有向箭頭向下連接。<br>• **底層（Y: 14~38）**：對應之「實證與處方卡」，並以水平虛線標示跨分支連結（Cross-links）。 |
| **T2：因果與演進流程軸**<br>*(Left-to-Right Pipeline)* | 轉型指南、方法論步驟、痛點至處方鏈條 | • **水平 3～4 個垂直欄位（Columns）**：由左至右為 `Col 1 [結構痛點]` $\xrightarrow{\text{成因診斷}}$ `Col 2 [理論/演算法破局]` $\xrightarrow{\text{機制轉換}}$ `Col 3 [階段處方]` $\xrightarrow{\text{價值收斂}}$ `Col 4 [終極護城河]`。<br>• 每欄外包一個 **Palmer 共同區域底色框（Macro Zone）**，內含 2 張垂直堆疊子卡。 |
| **T3：系統動力學雙迴路圖**<br>*(System Dynamics Loop)* | 商業生態、微宏觀經濟循環、雙向反饋、跨篇統整 | • **中央迴路區（X: 34~66）**：配置兩個核心實體（如：下方實線框「核心造血引擎」$\leftrightarrow$ 上方虛線框「外部助燃劑/環境約束」），以弧形有向箭頭連接並標註 `+ 增強 / - 調節` 謂詞膠囊。<br>• **兩側模組區（左 X: 4~30，右 X: 70~96）**：左右各配置共同區域容器，內含 2～3 張卡片連入中央。 |
| **T4：對照矩陣與雙欄架構**<br>*(Comparative / 2x2 Matrix)* | 典範轉移（舊 vs. 新）、人機分工、2×2 象限策略 | • **左右雙大區（左 X: 4~48 vs. 右 X: 52~96）** 或 **中央十字四象限**。<br>• 左區採用 `danger` 警示色條，右區採用 `primary`/`success` 破局色條；中央以雙向對照膠囊橋樑逐層比較。 |
| **T5：瑞士網格核心放射圖**<br>*(Swiss Hub-and-Spoke)* | 單一主題多維度剖析（痛點、理論、盲點、處方、思辨） | • **中央核心樞紐（X: 38~62, Y: 44~58）**：深色高對比核心卡。<br>• **左右對稱卡片（左 X: 4~33，右 X: 67~96）**：左 2～3 卡、右 2 卡（同欄等寬 `W=29`），所有連線附帶關係謂詞膠囊。<br>• **底部全寬收斂橫幅（X: 4~96, Y: 2.5~10.3）**。 |

## 二、 程式級渲染與抗破版硬性規則 `[依據：Purchase 1997; Tufte 1990; W3C CLREQ]`

直接匯入或擴充 [generate_mindmap.py](../scripts/generate_mindmap.py) 內建函數執行：

1. **畫布與無損銳利度參數**：
   - `figsize=(28, 18.5)`、`dpi=240`、`pil_kwargs={'quality': 98, 'subsampling': 0}`（強制關閉色度抽樣，消除中文字毛邊）。
   - 字型安全：僅使用基本幾何符號（`→`, `←`, `↔`, `●`, `★`），**嚴禁使用 Emoji** 以防缺字方框（Tofu box）。
2. **自動斷行與動態框高計算（100% 根絕文字出框與重疊）**：
   - 呼叫 `compute_card_height(bullets, max_em_width=20.5)`：依全形漢字 `1.0`、英數 `0.55` 自動斷行並加上懸掛縮排，精算出每張卡片所需高度 $H$，再依垂直間距 $\ge 2.5$ 排定 $Y$ 座標。
3. **Tufte 四層 Z-Order 深度分離**：
   - `zorder = 1`：`draw_macro_zone()` 繪製 Palmer 共同區域極淺底色容器框。
   - `zorder = 2`：`draw_labeled_bezier()` 繪製 **零交叉（Zero Edge Crossings, Purchase 1997）** 平滑連線。
   - `zorder = 3~4`：`draw_modern_card()` 繪製微陰影、純白/暖白卡面、左側 4pt 語意強調色條、標題膠囊與內文。
   - `zorder = 5`：連接線中點自動繪製 **Novak 關係謂詞膠囊標籤**（如 `導致權重失真`、`L1 懲罰收斂`），嚴禁無意義空白連線。

## 三、 產出後強制驗收 (Visual Quality Gate)
執行 Python 腳本生成圖片後，**必須呼叫 `read_file` 檢視生成的圖片檔**，確認：
- [ ] **0 文字穿框或截斷**、**0 卡片重疊**、**0 連線交叉打結**。
- [ ] 主要連接線皆具備清晰的 **Novak 關係謂詞膠囊標籤**，且整體留白率 $\ge 35\%$。
