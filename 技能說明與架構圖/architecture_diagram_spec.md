# 核心架構圖生成規格與重繪提示詞（Architecture Diagram Spec & Prompt）

> **文件用途**：完整記錄 `skill_architecture_overview.png` 的設計哲學、構圖規格、色票系統與文案紅線。日後若技能流程更新，只需將本檔連同 `generate_architecture_diagram.py` 交給 AI，即可在維持一致視覺風格的前提下快速修改或重繪。

---

## 一、 設計目標與資訊密度紅線（Content Boundaries）

1. **目標受眾**：一般外部使用者與初次接觸本技能的讀者（**不含**作者個人專屬的「作者直通模式」或雙倉庫私有還原細節）。
2. **閱讀目標**：讓人打開圖片 **10 秒內看懂** 這個技能「能做什麼、怎麼跑、有什麼特色」，而不是被技術細節嚇退。
3. **三大絕對禁止（Anti-Clutter Rules）**：
   - **嚴禁出現任何程式碼或規範檔名**（例如 `SKILL.md`、`router.md`、`hcl_color_engine.py`、`01_plan.md` 等）——檔名與細部模組分工一律交由 [技能介紹與架構指南.md](./技能介紹與架構指南.md) 說明。
   - **嚴禁塞入微規則與實作參數**（例如字級 `pt`、DPI、JSON 欄位名、函式名稱）。
   - **嚴禁使用時效性詞彙**（例如「本次更新」「新亮點」），一律採常駐型標籤 **`核心特色 1 / 2 / 3`**。

---

## 二、 畫布、字級與排版工程規範

| 項目 | 規格 | 備註 |
| :--- | :--- | :--- |
| **生成引擎** | Python `matplotlib`（純向量文字與圓角幾何，嚴禁擴散生圖模型） | 沿用 `generate_mindmap.py` 的 `configure_cjk_fonts()` 與 `sanitize_cjk_glyphs()` |
| **畫布尺寸與解析度** | `24.0" × 15.2"`、`240 DPI`（`5760 × 3648 px`）、座標 `0~100` | 橫式全景構圖，四周留白乾淨 |
| **背景色** | `#FAFBFD`（極淺冷白底） | 高對比、適合深淺色 GitHub 檢視 |
| **字級階梯** | 主標 `27.5pt Bold`、副標 `15.2pt`、分區標 `16.2pt Bold`、徽章 `12.6pt Bold`、卡片標 `14.0~14.8pt Bold`、內文 `12.4~13.0pt`、箭頭標籤 `11.8pt Bold` | 內文行距固定 `1.58×`，確保高可讀性 |
| **防撞與驗收** | 輸出前必呼叫 `verify_visual_outputs.check_matplotlib_text_collisions(fig)`，輸出後以目視確認零壓字、零穿框、雙軌走廊不重疊 | 對應腳本：`generate_architecture_diagram.py` |

## 四、 給 AI 的標準重繪／修改提示詞範本

日後若要調整圖片內容或新增功能模組，可直接複製以下提示詞給 AI 執行：

```text
請閱讀 `技能說明與架構圖/architecture_diagram_spec.md` 與 `技能說明與架構圖/generate_architecture_diagram.py`，
依照規格中的色票系統、字級階梯（內文 >= 12.4pt、行距 1.58×）、橫式分區結構與「嚴禁出現檔名與微規則、面向一般外部使用者」的資訊紅線，
進行以下更新並重新生成 `技能說明與架構圖/skill_architecture_overview.png`：

【本次要修改的項目】
1. （填入要修改的區塊或文案，例如：在格式 E 卡片補充 XXX）
2. （填入其他調整）

完成後請執行 `py 技能說明與架構圖/generate_architecture_diagram.py`，
確認 `check_matplotlib_text_collisions` 零碰撞，並直接打開輸出 PNG 目視檢查文字、行距與箭頭走廊是否完全乾淨無重疊。
```
